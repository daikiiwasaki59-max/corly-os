# 家計簿・資産形成（個人用）
無料・サーバー無し・端末内(localStorage)保存・外部送信なし。`python3 -m http.server` で開く。
- 入力: 収入/支出（日付・金額・カテゴリ・メモ）
- 今月: 収入・支出・収支・貯蓄率、カテゴリ別の支出（月の予算を設定すると超過を赤表示）
- 資産計画: 現在の資産・目標額・目標日・想定年利を入力 → 毎月の必要貯蓄額（月次複利の単純計算）、実績の平均収支との差、生活防衛資金の目安
- 数値はすべて入力値からの計算。年利0%・防衛資金6か月は「仮置き」で、自分で変更する。
- 投資判断・NISA/iDeCo・税は専門家（FP・税理士）に確認すること。
