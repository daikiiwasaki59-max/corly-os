# Muse Personal（完全個人用・無料）

Meta AI(Muse Spark)風のチャットを、**端末のブラウザ内でAIを動かして**再現したもの。
APIキー・サーバー・従量課金なし。会話はこの端末のブラウザ(localStorage)にだけ保存され、外部に送信されない。

## 使い方
```
cd muse-personal && npx serve .     # または python3 -m http.server
```
PC版 Chrome / Edge で開く → モデルを選んで「読み込み」（初回のみダウンロード）→ チャット。
※ WebGPU が必要。file:// 直開きは不可、http(s)経由で開くこと。

## 機能
- チャット（ストリーミング表示・停止）／Instant・Thinking 切替／履歴（複数会話）
- 画像添付（[画像可]モデルのみ）／音声入力（ブラウザ標準）
- モデル一覧はライブラリから実行時取得

## 限界（正直に）
- Thinking は「段階的に考える指示＋長めの出力」であり、Muse の Contemplating（並列マルチエージェント）ではない。
- 小型モデルのため、精度・日本語品質はクラウドの大型モデルより落ちる。事実確認が必要な内容（法務・税務・価格等）には使わない。
- 初回ダウンロードは大きい（モデルごとに異なる）。スマホは非力で、動かない場合あり。
- 画像生成・Live AI・Shopping は未実装。
