# 定期実行（Routine）の登録方法 — 岩崎が画面から行う

この環境からは「コネクタ付き」の定期実行を作れない（組織の設定）。**claude.ai/code の Routines 画面から3本作る。** 所要 10分程度（仮置き）。
既に動いている「投稿ネタ出し（毎朝7:00）」と同じ作り方。

## 共通設定
| 項目 | 値 |
|---|---|
| 環境 | Default |
| 毎回新しいセッション | ON |
| コネクタ | **Gmail、Google Calendar、Google Drive、Google Sheets** の4つ（週次レビューは Calendar 不要） |
| モデル | 岩崎の判断。投稿ネタ出しと同じ Sonnet で十分（コストが下がる） |
| 通知 | 朝の1通・週次: プッシュON ／ 夜のインサイド: OFF |

## 1. CORLY 朝の1通（admin）
- スケジュール: **毎日 6:30 JST**（UTC: `30 21 * * *`）
- プロンプト: `routines/prompts/morning-brief.txt` の中身をそのまま貼る
- 補足: この環境で試しに作った同名の Routine（コネクタ無し・無効化済み）がある。画面でそれを開いてコネクタを4つ足して有効化してもよいし、消して新規に作ってもよい。

## 2. CORLY 夜のインサイドセールス（inside-sales）
- スケジュール: **毎日 22:30 JST**（UTC: `30 13 * * *`）
- プロンプト: `routines/prompts/inside-sales-night.txt`

## 3. CORLY 週次レビュー（exec）
- スケジュール: **毎週月曜 7:00 JST**（UTC: `0 22 * * 0`）
- プロンプト: `routines/prompts/exec-weekly.txt`

## 登録後の確認
1. 朝の1通を「今すぐ実行」して、`【朝の1通】YYYY-MM-DD` のメールが届くか見る。
2. 届いたら返信で `所在地: / 電話: / メール:` の3行を送る。夜のインサイドが転記し、翌朝から送信候補が出る。
3. 動作は `data/log.csv`（リポジトリ）に残る。

## 止め方
Routines 画面で無効化。夜のインサイドを止めれば顧客への送信は完全に止まる（送信はこの1本だけが行う）。
