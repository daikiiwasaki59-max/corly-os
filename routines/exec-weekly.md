# 週次レビュー（exec）— 毎週月曜 7:00 JST

役職: `.claude/agents/exec.md`。共通前提: `routines/_common.md`。

## 目的
60日計画（`company/07_strategy.md` §5）に対する現在地を数字で出し、今週の一手を3つまで提案する。

## 手順
1. `routines/_common.md` §0 でリポジトリを最新にする。
2. 集計（全て実績値。出典はCSVの行）
   - 取引先CSV: 事業別 × ステージ別の件数
   - `data/approvals.csv`: 先週の 依頼 / 承認 / 却下 / 送信 件数
   - `data/log.csv`: 部隊の稼働（実行回数、送信・返信・下書きの合計）
   - 60日目標との差: 初回接触 40社 / 商談 8社 / 提案 4社 / 受注 管理会社1社＋燃料大口2件
3. 横断チェック（`company/08_operating_model.md` §運用のルール5）
   - 事業＝清掃 と 事業＝燃料 に同じ会社（重複キー一致）がいないか
   - メモに「重機」「車両」「トラック」を含む管理会社がいないか（燃料の候補にもなる）
4. 書く
   - `docs/reviews/YYYY-MM-DD.md` に: 結論3行 / 数字の表 / 停滞と仮説 / 今週の一手（最大3、1行1案、番号つき） / 岩崎への質問（1つまで）
   - 同じ内容を Gmail で 件名 `【週次レビュー】YYYY-MM-DD` として岩崎へ
5. `data/log.csv` に1行追記し、commit / push。

## やらない
- 会社知識・戦略ファイルの書き換え（提案まで）。顧客への連絡。
