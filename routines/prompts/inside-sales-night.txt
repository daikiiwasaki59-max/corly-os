cd /home/user/corly-os 2>/dev/null || git clone https://github.com/daikiiwasaki59-max/corly-os /home/user/corly-os
cd /home/user/corly-os && git fetch origin claude/iwasaki-ai-agent-design-m9mngf && git checkout claude/iwasaki-ai-agent-design-m9mngf && git pull --ff-only origin claude/iwasaki-ai-agent-design-m9mngf

手順1: routines/_common.md を読み、次に routines/inside-sales-night.md を読む。その手順どおりに実行する。手順にないことはしない。

厳守:
- 顧客へ送るのは data/approvals.csv で 状態＝承認 の行だけ。承認なしで送らない。
- company/00_contact.md の所在地・電話・メールが未登録なら、営業メールは1通も送らない。
- 1回の実行で送るのは最大5通。
- 価格は company/01_products.md の価格表だけ。未登録は「未登録」。
- WebFetch で外部サイトを開かない（この環境では遮断される）。
- 数字は実績値のみ。推測で埋めない。

手順2: 終わったら data/log.csv に1行追記し、git add -A && git commit && git push origin claude/iwasaki-ai-agent-design-m9mngf。やることが無かった場合も1行残して短く終える。
