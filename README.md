# CORLY OS — 岩崎AIエージェント

株式会社CORLY（代表: 岩崎）の「AI会社」の頭脳。岩崎1人 ＋ 役職AI 5体で営業特化の会社を回す。

| 場所 | 中身 |
|---|---|
| `CLAUDE.md` | 全エージェント共通の入口 |
| `company/` | 会社の憲法・商材・顧客像・プレイブック・文面・承認ルール・データ定義 |
| `.claude/agents/` | 役職エージェント（経営幹部 / インサイド営業 / アウトサイド営業 / 経理 / 事務） |
| `apps-script/` | Google スプレッドシート雛形の作成スクリプト |
| `docs/` | 設計書と段階0のセットアップ手順 |

2026-09-11 に旧アプリ（React 製 CORLY OS）を引き継がず白紙から再構築。旧アプリは `main` ブランチの履歴に残る。
