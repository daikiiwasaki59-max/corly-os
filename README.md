# CORLY OS

AI社員が記事を書き、社長が承認し、自動で投稿され、売上が自動で集まる —
**1人で回すAIカンパニーの管理OS**です。

```
朝6:00  AI社員が下書きを書く
  ↓
社長が承認する（1タップ）
  ↓
X / Threads / WordPress へ自動投稿
  ↓
Stripe・ASPの売上を自動で取り込む
  ↓
19:00  報告グループに本日の売上が流れる
```

サーバー不要。バックエンドは Google Apps Script、DBはスプレッドシートです。

## 画面

| 画面 | 役割 |
|---|---|
| 🏢 オフィス | 部署ごとの本日の売上・AI社員の稼働・報告グループ |
| 📥 承認 | AIが書いた下書きを承認／却下する。**ここが自動投稿のゲート** |
| 💰 売上 | 部署別・商品別の内訳と構成比 |
| ⚙️ 設定 | バックエンド接続、手動実行 |

## 使いはじめる

```bash
npm install
npm run dev
```

初回は **デモデータ** で動きます。実データを流すには
**[docs/SETUP.md](./docs/SETUP.md)** の手順（30分）を実行してください。

## 構成

```
src/                      ダッシュボード（React + Vite）
  config/company.js       部署・AI社員・投稿チャネルの定義
  screens/                オフィス／承認／売上／設定
backend/gas/              Apps Script（バックエンド）
  00_Config.gs            部署定義・売上取り込み元
  03_Agents.gs            Claude で下書きを書かせる（バッチ）
  04_Publish.gs           承認済みを各SNSへ投稿
  05_Revenue.gs           Stripe / Gmail から売上を取り込む
  07_Triggers.gs          自動運転のスケジュール
```

## 先に知っておくこと

- **note には公開APIがありません。** 自動投稿はできず、承認後にコピーして人が貼る運用です
- **X の無料枠は書き込み回数がごく少ない**ため、実運用には有料プランが必要です
- **アフィリエイト売上は「発生」ベース**です。後から取り消されます。入金額ではありません
- **承認を人が挟む設計**です。規約・法令（ステマ規制など）と信用を守るための意図的な設計で、全自動にはしていません

詳細と回避策は [INTEGRATIONS.md](./docs/INTEGRATIONS.md) にあります。
