# 段階0（土台）のセットアップ手順

所要: 岩崎の作業 30分程度（仮置き）。

## 1. スプレッドシート「CORLY OS」を作る
1. Google スプレッドシートを新規作成し、名前を「CORLY OS」にする。
2. メニュー [拡張機能] → [Apps Script] を開く。
3. `コード.gs` の中身を全て消し、このリポジトリの `apps-script/setup-sheets.gs` を貼り付けて保存する。
4. 関数の選択で `setupCorlySheets` を選び、[実行]。権限の承認画面が出たら自分の Google アカウントで承認する。
5. 取引先・案件・活動・見積・請求・価格表・承認待ち・日報 の8シートができていることを確認する。
6. スプレッドシートの URL を `company/INPUT_REQUIRED.md` の「6. ツール」に書く（Claude に伝えても可）。

## 2. 会社情報を入れる
`company/INPUT_REQUIRED.md` の項目を、優先度順に埋める。
1. 会社の基本（所在地・電話・メール）。これがないとメールのフッターが作れない。
2. 燃料の報酬体系と、顧客に言ってよい範囲。これがないと燃料の文面が作れない。
3. 清掃の価格表。これがないと見積が作れない。
4. ICP。これがないとリストの優先度が付けられない。

Claude のチャットで「所在地は〇〇、電話は〇〇」と伝えれば、事務エージェントが該当ファイルに転記する。

## 3. 既存リストの取り込み
- 現在の顧客・見込みリスト（Excel など）を「取引先」シートの列に合わせて貼り付ける。
- 列が合わない場合は Claude に「この Excel を取引先シートの形式に直して」と頼む。**個人名を含む列は必要な先だけ残す。**
- 燃料の数百〜数千件は「事業＝燃料」「ステージ＝未接触」「リスト出所」を必ず入れる。

## 4. 動作確認
Claude Code でこのリポジトリを開き、以下を順に試す。
1. 「admin、INPUT_REQUIRED の未入力を一覧にして」
2. 「exec、取引先シートの事業別・ステージ別の件数を出して」
3. 「inside-sales、燃料の優先度高・未接触から5件選んで初回メールの下書きを承認待ちに入れて」（会社の基本情報が入ってから）

## 5. 段階1以降（この後）
| 段階 | 内容 | 前提 |
|---|---|---|
| 1 事務 | LINE 公式アカウント作成 → Messaging API → Apps Script から岩崎へ朝の1通を送る定期実行 | 岩崎が LINE 公式アカウントを作る |
| 2 インサイド | リスト→下書き→承認→送信→返信要約の運用 | 1〜4 が済んでいる |
| 3 経理 | freee 読み取りで未入金一覧、請求の下書き | freee の会社IDと権限 |
| 4 経営幹部 | 月曜・金曜の定期レビュー | 活動データが2週間分ある |
| 5 アウトサイド | 訪問パックと活動ログ化 | プレイブックに岩崎のトークが載り始めている |

## 注意
- Apps Script の URL・LINE のチャネルトークン・freee の認証情報はリポジトリに置かない。Apps Script のスクリプトプロパティか、各サービスの設定画面に置く。
- スプレッドシートを他人と共有すると顧客情報が見える。共有設定は岩崎のみに保つ。
