# ジャーナル（日次 / 週次 / 月次 / PDCA）をアプリに統合する

これまで別々の Google フォーム4本に分かれていた記録を、CORLY OS の「📔 ジャーナル」画面1つにまとめました。送信先はこれまでと同じスプレッドシート **「ジャーナル」** で、タブも従来どおりです。

| アプリのタブ | 送信先タブ | 設問数 |
| --- | --- | --- |
| 🌙 日次 | `daily` | 11問（うち点数2問） |
| 📅 週次 | `weekly` | 8問（うち点数1問） |
| 🗓 月次 | `monthly` | 10問（うち点数2問） |
| 🔁 PDCA | `フォームの回答 1` | 日付＋5問 |

点数（幸福度・エネルギー・人生満足度）は **1〜10** の10段階です。

## 1. Apps Script を設置する

1. スプレッドシート「ジャーナル」を開く
2. メニューの [拡張機能] → [Apps Script] を開く
3. 開いている `コード.gs`（`Code.gs`）の中身を全て削除する
4. このリポジトリの `apps-script/journal.gs` の内容をコピーして貼り付ける
5. 保存する

> 既に日報用の `daily-report.gs` を別のスプレッドシートに入れている場合、それとは**別のプロジェクト**になります。混ぜないでください。

## 2. ウェブアプリとして公開する

1. 右上の [デプロイ] → [新しいデプロイ]
2. 種類の選択（歯車アイコン）で「ウェブアプリ」
3. 「実行するユーザー」→ 自分
4. 「アクセスできるユーザー」→ 全員
5. [デプロイ] → 権限の承認画面が出たら自分の Google アカウントで承認
6. 発行された **ウェブアプリのURL**（`https://script.google.com/macros/s/XXXX/exec`）をコピー

動作確認：このURLをブラウザで開いて `{"status":"ok", ...}` が表示されれば設置成功です。

## 3. CORLY OS 側で接続する

1. 下部ナビの「📔 ジャーナル」を開く
2. 上部の「⚠️ スプレッドシート未接続」をタップ
3. コピーしたURLを貼り付け、入力欄からフォーカスを外す（自動保存されます）
4. 「🔗 スプレッドシート連携：接続済み」に変われば完了

## 4. 使い方

- 上部の4タブを切り替えて入力します。**日曜は週次、月末は月次**のタブに金色の点が付きます。
- 入力途中でタブを切り替えても内容は消えません（この端末に自動保存）。
- 1問以上入力すれば送信できます。全問必須ではありません。
- 送信すると下書きがクリアされ、下の「📚 直近の記録」に残ります。
- 未接続のまま送信した記録は「未送信」と表示されます。URLを設定したあとに **[再送信]** を押せばシートに追記されます。

## 仕様上の注意

- **送信結果の保証**：Apps Script の CORS 制約により、ブラウザからはシートに書けたかを確認できません。「✓ 記録しました」はネットワーク送信が成功したという意味で、シート側の成否ではありません。初回は必ずスプレッドシートを開いて行が増えているか目視確認してください。
- **書き込み先の決め方**：列の位置ではなく、シート1行目の**見出し名**で書き込み先を決めています。列を入れ替えても壊れませんが、**見出しの文言を変えるとその列だけ空になります**。見出しを変える場合は `src/journal.js` の `header` も同じ文字列に直してください。
- **`daily` タブの重複列**：`Q1. 今日の幸福度は何点？` と `Q1. 今日の幸福度は何点？ 2`（Q2も同様）は、フォームを編集した名残で2列に分かれています。どちらの列を参照しているグラフ・数式があっても壊れないよう、**同じ点数を両方の列に書き込みます**。片方を使っていないなら、その列を削除すれば以後1列だけになります。
- **元の Google フォーム**：このアプリは元フォームを経由せず、直接シートに追記します。フォームは残しておいても害はありませんが、フォームから送信した分とアプリから送信した分が同じタブに混ざります。フォーム側は受付終了にしておくと混乱しません（過去の回答データは消えません）。
- **URLの保存場所**：ウェブアプリURLはこの端末のブラウザ（localStorage）にのみ保存されます。外部には送信されません。端末を変えると再設定が必要です。
- **共有時の注意**：スプレッドシート「ジャーナル」を他人と共有すると、個人的な記録がそのまま相手に見えます。共有設定は変更しないことを勧めます。
- **デプロイの更新**：`journal.gs` を修正したあと「新しいデプロイ」を作るとURLが変わります。同じデプロイを「編集」で更新すればURLは変わりません。
