# 営業フロー — リスト作成から成約まで（AI ＋ 岩崎）

作成日: 2026-09-12 / 対象: 管理会社向け 原状回復 一気通貫 ／ 燃料（パトロール給油）
前提: 送信・発行・契約は岩崎の承認が必要（`company/05_approval_policy.md`）。正データは スプレッドシート「CORLY OS」。

## 全体（7工程）
```
①リスト作成 →②選別 →③文面作成 →④承認 →⑤送信 →⑥返信管理 →⑦商談・成約
   AI            AI        AI        岩崎      AI        AI        岩崎＋AI
```

| 工程 | 誰 | やること | 出力先 |
|---|---|---|---|
| ①リスト作成 | inside-sales | 公開名簿・自社サイトから会社名・所在地・電話・URL を取得。重複除去 | 取引先シート（ステージ＝未接触） |
| ②選別 | inside-sales | ICP に照らして優先度 高/中/低。連絡NG・協力業者顧客を除外 | 取引先シートの優先度列 |
| ③文面作成 | inside-sales | `04_templates.md` の型に差し込み。1通ずつ | 承認待ちシート ＋ Gmail 下書き |
| ④承認 | **岩崎** | 承認待ちシートの状態列を「承認」に。修正なら「修正」＋メモ | 承認待ちシート |
| ⑤送信 | inside-sales | 承認済みだけ送信。送信日を活動シートに記録 | 活動シート |
| ⑥返信管理 | inside-sales | 返信を要約（相手/要旨/温度感/次アクション/期限）。不在・未返信は追客リマインド | 活動シート・次アクション |
| ⑦商談・成約 | 岩崎（＋福源屋の現調）、outside-sales が前後を支援 | 訪問パック → 商談 → 提案 → 見積/与信申請 → 成約 | 案件シート |

## 1日の型（岩崎の所要: 30〜60分。仮置き）
| 時間 | 内容 |
|---|---|
| 朝 | admin から LINE で1通（承認待ち件数・今日の期限・今日の予定）。承認待ちを承認/修正 |
| 日中 | 訪問・商談。移動中に outside-sales へ一言メモ（「〇〇に行った、こう言われた」） |
| 夕 | outside-sales が活動ログと日報を下書き。岩崎が確認 |

## 承認の上限
1日の送信候補は **岩崎が承認できる件数が上限**。初期は 1日2〜3通（仮置き。`docs/research/sales-strategy-pm.md` の週次計画に合わせる）。数を増やすより、1通の質と相手固有の1行を優先する。

## ②選別の基準

## 現在の環境の制約
この Claude 環境は **外部サイトの本文取得が遮断** されている（検索はできる）。上記の名簿サイトを直接読めないため、①リスト作成は次のいずれかで行う。
1. 岩崎がスマホ/PCで名簿を開き、画面か PDF をチャットに貼る → AI が取引先シートの形式に起こす（**今すぐできる**）
2. claude.ai/code の環境設定でネットワークアクセスを緩め、新しいセッションで実行
3. 岩崎のPCの Claude Code でこのリポジトリを開いて実行
