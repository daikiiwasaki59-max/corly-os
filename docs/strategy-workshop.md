# 戦略ワークショップ（MVV → ゴール → 部署 → 60日計画）

作成日: 2026-09-11 / 状態: 岩崎の回答待ち。方針はアジャイル（2週間スプリント × 4 ＝ 60日。走りながら修正）。

## 0. 進め方
```
① 岩崎個人の MVV（インタビュー §1）
② ゴール（12か月 と 60日。§2）
③ 部署の役割（ゴールから逆算。§3）
④ 60日計画（§5）。2週間ごとに exec が振り返り、修正
```
方向性が違えば下流は全部無駄になるので、①②を先に固める。③④は仮説を置いて走らせる。

## 1. 個人 MVV インタビュー（岩崎が答える）
1. 3年後、どんな1日を過ごしていたいか（時間の使い方・場所・誰と・現場に出ているか）。
2. 何のために稼ぐのか。月いくらの利益があれば「現場離脱」と言えるか（仮置きでよい）。
3. これまでで一番手応えがあった仕事は何か。なぜ手応えがあったか。
4. 絶対にやりたくないこと（仕事の種類、客の種類、働き方）。
5. 他の営業・他の業者より自分が勝てていると思う点。
6. 判断で大事にしている基準（既に設定済みの「法令・信用 → 継続収益 → 実行可能性 → スピード」以外で）。
7. 会社を「何屋」と呼ばれたいか（清掃屋 / 燃料屋 / 営業屋 / 管理会社の裏方 など）。

回答を元に exec がミッション（何のために）・ビジョン（3年後の姿）・バリュー（3〜5個の行動基準）の候補を2案ずつ出し、岩崎が選ぶ。

**exec の仮説（岩崎の回答で確認する）**: 清掃も燃料も、岩崎の役割は「営業機能を持たない事業者（工務店・燃料代理店）の営業窓口になる」こと。両事業に共通する強みは営業力であり、商材ではない。ミッションはここに寄る可能性がある。

## 2. ゴール設定に必要な数字（未登録）
| 項目 | 用途 |
|---|---|
| 現在の月売上（清掃 / 燃料）と月固定費 | 現在地。自転車操業の度合いを数字にする |
| 清掃の月間戸数と1室あたり粗利（原価・作業時間） | 清掃の「1室いくら残るか」 |
| 燃料の顧客1件あたり典型的な月間数量（L） | 目標利益 ÷ 取り分 ÷ 1件あたり数量 ＝ 必要件数 |
| 「現場離脱」の月利益（§1 の質問2） | 12か月ゴール |

燃料の逆算式（数字は岩崎が入れる）:
```
必要月間数量(L) = 目標月利益(円) ÷ 取り分(円/L)
必要顧客数     = 必要月間数量 ÷ 顧客1件の月間数量
必要商談数     = 必要顧客数 ÷ 成約率（初回は仮置き）
```

## 3. 部署の役割（ゴール確定後に確定。以下は骨組み）
| 部署 | 責任 | 成果指標 | 隣へ渡すもの |
|---|---|---|---|
| 経営幹部 | ゴールとの差分把握、優先順位、2週間ごとの戦略修正 | ゴール達成率、提案採用率 | 各部署への「今スプリントの一手」 |
| 営業（インサイド） | リスト整備 → 選別 → 初回接触 → 返信管理 → アポ | 承認済み送信数、返信率、アポ数 | アウトサイドへ「訪問パック」 |
| 営業（アウトサイド） | 訪問 → 提案 → 与信申請 / 見積 → 成約 | 商談数、与信申請数、成約数 | 経理へ「契約情報・数量・単価」 |
| 経理 | 請求・入金・報酬照合（燃料は翌月末入金の照合）・月次粗利 | 請求漏れ0、未入金日数 | 経営幹部へ「月次の数字」 |
| 事務 | 承認待ちの集約、期限、書類、会社知識の更新 | リマインド漏れ0 | 全部署へ「朝の1通」 |

## 4. 事業別の初期仮説（exec。全て仮説。岩崎の反論待ち）

### 4-1. 清掃
**構造の読み**: 価値は「管理会社との関係」と「退去立会＋工事の手配」を持つ層にある。清掃単体は最下層で価格を押し下げられる（実績値: 岩崎回答の構造）。

**階段（ステージ）案**
| ステージ | 立ち位置 | 単価の目安 | 何を得るか |
|---|---|---|---|
| 0（今） | 工事業者の下請け清掃 | 1K 8,000〜9,000円（実績値） | 戸数 |
| 1（60日） | 「組む工務店」の専属清掃 ＋ 岩崎が管理会社を営業して工務店へ案件を持ち込む | 下請け単価のまま。ただし戸数を岩崎が作る | 工務店に対する交渉力（案件を持ってくる側になる） |
| 2（3〜6か月） | 小規模管理会社から「立会＋原状回復＋清掃」を直請け。工事は組む工務店へ発注 | 1K 13,000円（実績値）＋ 工事マージン（未登録） | 商流の上位。単価決定権 |
| 3（6〜12か月） | 管理戸数の多い管理会社と年間で受ける | 未登録 | 安定戸数。外注を使える粗利 |

**岩崎の案への指摘**
- 「工務店経由で受ける」だけでは単価は 8,000〜9,000円のままで、自転車操業は解消しない。工務店との組みを「下請け」ではなく「岩崎が案件を取ってくる代わりに、立会・直請けの窓口を岩崎にさせる」形にできるかが分岐点。
- TTP の対象は「1〜2段上」の事業者。大阪で管理会社直請けの原状回復を回している中小事業者が対象。**実在企業の名指しは、Web 検索で出典を付けてから行う（推測では書かない）。** 次のステップで exec が候補を出典つきで出す。
- ビジネスモデルの型は3つ。①原状回復ワンストップ型（立会〜工事〜清掃を一括で管理会社から受ける）②清掃特化スケール型（多拠点・人を回す）③管理会社の裏方型（入退去業務の代行）。岩崎1人で狙えるのは①の小規模版。②は人が要るので今は無理。

### 4-2. 燃料
**構造の読み**: 岩崎の利益 ＝ 数量 × 取り分。取り分は配送料に左右される。配送料が安いエリア（大阪市内、明石〜尼崎。RIM+7円 見込み、仮置き）では RIM+15円 のエリアより 8円 の余地があり、価格で勝つか取り分を厚くするかを選べる。

**仮説**
1. 商圏は「大阪市内 ＋ 阪神間」に絞る。理由は配送料の差（仮置き）。
2. 狙う顧客は「月間数量が大きい先」。件数より1件あたりの数量。燃料の種類と業種が未登録のため、選別基準はまだ作らない。
3. 協力業者6社の既存顧客を触らないための「接触前チェック」を工程に固定する。除外リストの入手方法が決まるまで新規接触を始めない。
4. 与信 → 契約に時間がかかるため、60日の成果指標は「成約数」ではなく「商談数・与信申請数」に置く。
5. ヒラオカ石油・平野石油の顧客が切り替える理由（価格差か、対応か、支払条件か）が未登録。**ここが分からないと文面が作れない。**

**岩崎の案への指摘**
- 「カミックスのリストを食い散らかす」は、リストの出所次第で不正競争防止法の論点になる。出所が説明できるリストだけ使う。
- 「LIOAS の岩崎」として動く根拠（契約書・名刺）を先に揃える。顧客から見て契約主体がモリカワ商事である説明を、初回接触から一貫させる。
