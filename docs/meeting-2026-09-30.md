# 会議 2026-09-30 — 契約を取ってくる体制

参加: 経営幹部（exec）、A 契約はどこで決まるか、B 部隊の24時間設計、C 1人で回るかの現実確認、D 高優先21社の電話番号、E 尼崎のミニローリー会社の洗い出し。各報告は `docs/meeting-2026-09-30/`。
岩崎の前提（当日）: 訪問は岩崎が行う。営業は清掃（管理会社）と燃料。**燃料は尼崎の特定スタンドで仕入れているミニローリー会社が新ターゲット**（モリカワ商事がその近くで燃料販売を始めるため）。

## 1. 結論（5行）
1. **契約は対面で決まる。** 管理会社＝お試し立会1件と写真つき報告、燃料＝現場を見て数量と時間帯を把握 → 与信 → モリカワ商事の契約。メール・SNS・提案書では決まらない。
2. **部隊の主軸を「メール新規開拓」から「電話→訪問の前後を支える」に組み替えた。** 夜が翌日のコールリスト（10社・番号・前回・固有の1行・想定反論）を作り、朝が渡し、岩崎が電話と訪問をし、一言メモを返信し、夜がログ化して次を作る。承認も一言メモも「朝の1通への返信1本」に統一。
3. **10月第1〜2週は営業に使える時間が週8〜10時間（仮置き）。** 譲渡・清算・条件メールが先。営業は「1日3〜5本の狙った電話」から。1日200件のテレアポではない。
4. **燃料は仕切り直し。** ターゲットが「エンド顧客42社」から「尼崎のミニローリー会社」に変わった。モリカワ商事の新拠点の条件（場所・開始時期・営業時間・掛売り・油種）が岩崎から入るまで、部隊は燃料に触らない。
5. **SNSの投稿ネタ出しは契約に直接効かない。** 止めずに目的を「電話後に検索されたときの信用ページ」に変え、週1本・4種に絞る。60日で効果が見えなければ止める。

## 3. 岩崎が決めること（部隊が勝手に決めない）
1. 「テレアポはやらない」（07_strategy §4-1）と「電話→訪問」の整合。会議の解釈は「無差別の大量架電はやらない。狙った1日3〜5本はやる」。これでよいか。
2. 1日のコールリストは10社でよいか（岩崎の時間から見て5社に減らすか）。
3. 留守は3回で打ち止め（郵送・低優先に回す）でよいか。
4. 土日はコールリストを作らないでよいか。
5. 燃料の新ターゲットの条件（`INPUT_REQUIRED.md` §0-4）。

## 4. 岩崎が今週やること（会議C。AIにはできない。所要は仮置き。合計10〜11時間）
1. 譲渡契約書の競業避止・秘密保持・代表者個人の条項を読み、弁護士に「個人で他社へ営業してよいか」を1問（1.5〜2h）。10/1 に署名したら直せない。
2. 大槻の転籍同意と取引先・外注先の承諾を回収（3h）。10/1 を過ぎると契約が CORLY に残る。
3. 庄栄興産へ条件メール（分配率・支払期日・名乗り・名刺表記）。できれば面談で率を決める（1.5h）。
4. LIOAS／モリカワ商事へ: 支払先を岩崎個人へ、既存顧客の照会方法、**尼崎の新拠点の条件**（0.5h）。
5. 部隊の栓を抜く3点: 会社基本3行を返信／Routines 3本を画面から登録（`routines/TRIGGERS.md`）／Sheets の権限（1h）。電話番号は部隊側で20件取得済み。
6. 大槻に「10月あと何室受けられるか」と直請け・下請けの内訳を聞く（0.2h）。
7. 税理士に: 譲渡対価の入金日、退職金の支給月と概算、生活費に対する滑走路の月数（1h）。
