# 連携できるもの・できないもの（正直な一覧）

「全部自動」と言い切れない部分があります。ここを誤解したまま作ると、
アカウント停止や集計ズレで手戻りが出ます。最初に読んでください。

## 投稿（アウトプット側）

| 販路 | 自動投稿 | 必要なもの | 注意点 |
|---|---|---|---|
| **X（旧Twitter）** | ✅ できる | 開発者アカウント／OAuth 2.0 のクライアントIDとリフレッシュトークン | 無料枠は書き込み回数がかなり少なく、実運用には有料プランが要ります。**現在の枠と価格は必ず公式で確認してください**（頻繁に変わります） |
| **Threads** | ✅ できる | Threads API のアクセストークン＋ユーザーID | コンテナ作成→公開の2段階。トークンに有効期限があり、定期的な更新が要ります |
| **WordPress（ブログ・LP）** | ✅ できる | サイトURL／ユーザー名／アプリケーションパスワード | いちばん安定します。自分のサーバーなので規約リスクもありません |
| **Instagram** | △ 条件つき | プロアカウント＋Facebookページ連携＋Graph API | 画像が公開URL上にある必要があり、テキストだけの投稿はできません |
| **note** | ❌ できない | — | 公開APIがありません。非公式な自動化は規約違反のリスクが高く、**実装していません**。下書きをコピーして人が貼る運用にしています |

**要点**：自分の資産（WordPress）はいくらでも自動化できます。他社プラットフォーム
（X・note・Instagram）は相手の規約の中でしか動かせません。
**収益の柱を他社SNSだけに置かない**のが、この構造でいちばん大事な設計判断です。

## 売上（インプット側）

| 収益源 | 自動取り込み | 方法 | 精度 |
|---|---|---|---|
| **Stripe** | ✅ できる | API から直接取得 | 高い。決済系はこれが正 |
| **Amazonアソシエイト** | △ | レポートメール or CSV | 確定値は後日変わります |
| **楽天アフィリエイト** | △ | レポートメール | 同上 |
| **A8.net / もしも** | △ | 成果発生メールを正規表現で解析 | メール書式が変わると壊れます |
| **note** | ❌ 手動 | ダッシュボードから手入力、またはシートに直接記入 | — |
| **BOOTH / Tips** | ❌ 手動 | 同上 | — |

### アフィリエイト売上の「確定」について

多くのASPで、成果は **発生 → 承認 → 確定** と段階を踏み、途中で取り消されます。
CORLY OS が集計しているのは基本的に **発生ベース** です。
ダッシュボードの数字は「今日の見込み」であって、入金額ではありません。
月次の確定額は各ASPの管理画面で必ず突き合わせてください。

## 法令まわりで外せないもの

- **ステマ規制（景品表示法）** — 広告なら「PR」「広告」の明示が必須です。AIへの指示文（`HOUSE_RULES`）に入れていますが、**最終確認は承認画面で人がしてください**。
- **薬機法** — 健康・美容ジャンルで効果を断定すると違反になります。このジャンルを扱うなら、承認のハードルを上げてください。
- **著作権** — AIの生成物でも、既存文章に酷似すれば問題になります。
- **各SNSの自動化ポリシー** — 「大量・無差別」が禁止の中心です。1日数本を人が承認して出す運用は、この線を越えません。

## 現実的な収益の伸ばし方

この構造は「ボタンを押したらお金が湧く」ものではありません。実際に効くのは：

1. **WordPress + アフィリエイト（自分の資産）** — 規約リスクがなく、記事は積み上がる。ただし成果が出るまで3〜6か月かかります
2. **Stripe + 自社コンテンツ** — 利益率が最も高く、集計も正確
3. **X / Threads** — 集客の入口。ここ単体で稼ぐのではなく、1と2へ送る導線として使う
4. **note** — 自動化できない代わりに、初速が出やすい

AIが効くのは **「量」を出す工程**（記事の下書き・投稿文・LP改善案）です。
**何を売るか・誰に売るか**の判断は自動化できません。そこが社長の仕事として残ります。
