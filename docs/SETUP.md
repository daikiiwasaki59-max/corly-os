# セットアップ手順

所要時間の目安：**STEP 1〜4 で30分**（ここまでで会社が動きます）。
SNS連携（STEP 5）は使うものだけ、後から足せます。

---

## STEP 1. スプレッドシートと Apps Script を用意する

1. Google スプレッドシートを新規作成する（名前は「CORLY OS」など任意）
2. メニューの **[拡張機能] → [Apps Script]** を開く
3. デフォルトの `コード.gs` を削除する
4. `backend/gas/` の中の **7ファイルすべて** を、同じ名前でファイルを作って貼り付ける
   - `00_Config.gs` `01_Sheets.gs` `02_Api.gs` `03_Agents.gs` `04_Publish.gs` `05_Revenue.gs` `06_Report.gs` `07_Triggers.gs`
   - Apps Script 側では拡張子なしのファイル名（`00_Config` など）で作ります

> シートは初回アクセス時に自動生成されるので、手で作る必要はありません。

---

## STEP 2. 秘密情報を登録する

Apps Script の左メニュー **⚙️ プロジェクトの設定 → スクリプト プロパティ** で登録します。
**コードには絶対に書かないでください。**

| プロパティ名 | 値 | 必須 |
|---|---|---|
| `API_TOKEN` | 自分で決める長い文字列（例：32文字のランダム英数字） | ✅ |
| `ANTHROPIC_API_KEY` | Claude API のキー（console.anthropic.com で発行） | ✅ |

`API_TOKEN` は「ウェブアプリURLを知っている人が誰でも操作できてしまう」のを
防ぐための合言葉です。適当な短い値にしないでください。

---

## STEP 3. ウェブアプリとして公開する

1. 右上の **[デプロイ] → [新しいデプロイ]**
2. 歯車アイコンから **「ウェブアプリ」** を選ぶ
3. **実行するユーザー：自分**
4. **アクセスできるユーザー：全員**
5. [デプロイ] → 権限の承認画面が出るので自分のGoogleアカウントで承認
6. 発行された URL（`https://script.google.com/macros/s/.../exec`）をコピー

> 「アクセスできるユーザー：全員」でも、`API_TOKEN` がないと何も操作できません。
> コードを更新したときは、**同じデプロイを「編集」で更新すれば URL は変わりません**。
> 「新しいデプロイ」を作ると URL が変わるので、その場合は STEP 4 をやり直します。

---

## STEP 4. ダッシュボードを繋ぐ

```bash
npm install
npm run dev      # http://localhost:5173
```

1. ブラウザで開き、下部ナビの **⚙️ 設定** を押す
2. STEP 3 でコピーした **ウェブアプリURL** を貼る
3. STEP 2 で決めた **API_TOKEN** を貼る
4. **[保存して接続テスト]** → 「接続できました」と出れば完了

続けて Apps Script のエディタに戻り、関数 **`selfTest`** を実行してください。
実行ログに `OK` が並べば設定は正常です。

最後に **`installTriggers`** を1回実行します。これで自動運転が始まります。

| 時刻 | 動くもの |
|---|---|
| 毎朝 6:00 | 各部のAI社員が下書きを書き始める |
| 10分おき | 書き上がった下書きを承認キューに積む |
| 15分おき | 承認済みを実際に投稿する |
| 1時間おき | 売上レポートを取り込む |
| 12:00 | 承認待ちが溜まっていたら催促 |
| 19:00 | 本日の売上報告がグループに流れる |

---

## STEP 5. 投稿先・売上取り込みを繋ぐ（任意）

使うものだけ、スクリプトプロパティに追加します。
各サービスの制約は **[INTEGRATIONS.md](./INTEGRATIONS.md)** を先に読んでください。

### WordPress（いちばん簡単・おすすめ）

| プロパティ | 取得方法 |
|---|---|
| `WP_BASE_URL` | `https://example.com`（末尾スラッシュなし） |
| `WP_USER` | WordPress のログインユーザー名 |
| `WP_APP_PASSWORD` | 管理画面 → ユーザー → プロフィール → 「アプリケーションパスワード」で発行 |

### X（旧Twitter）

| プロパティ | 取得方法 |
|---|---|
| `X_CLIENT_ID` / `X_CLIENT_SECRET` | X Developer Portal でアプリを作成（OAuth 2.0 を有効化） |
| `X_REFRESH_TOKEN` | `tweet.write offline.access` スコープで認可し、取得したリフレッシュトークン |

> X はリフレッシュトークンを使うたびに新しい値を返します（ローテーション）。
> CORLY OS は自動で保存し直すので、手動更新は不要です。

### Threads

| プロパティ | 取得方法 |
|---|---|
| `THREADS_USER_ID` | Threads API のユーザーID |
| `THREADS_ACCESS_TOKEN` | 長期アクセストークン（期限切れ前に更新が必要） |

### Stripe（コンテンツ販売の売上）

| プロパティ | 取得方法 |
|---|---|
| `STRIPE_SECRET_KEY` | Stripe ダッシュボード → 開発者 → APIキー（`sk_live_...`） |

### ASP の成果メール

`00_Config.gs` の `REVENUE_SOURCES` を、実際に届くメールに合わせて調整します。
**ASPのメール書式は各社バラバラなので、ここは実物を見ながら直す前提の場所です。**

```js
{
  id: 'a8',
  deptId: 'affiliate',
  kind: 'gmail',
  query: 'from:a8.net newer_than:2d',        // Gmailの検索式そのまま
  itemPattern: /^(.+?)\s+([\d,]+)\s*円/gm    // 1番目=商品名, 2番目=金額
}
```

調整のコツ：実際のメールを開き、**商品名と金額が並んでいる行**を1行コピーして、
その形にマッチする正規表現を書きます。うまく取れないときは `log` シートを見てください。

## 公開する（スマホから見られるようにする）

```bash
npm run build     # dist/ が生成される
```

`dist/` を GitHub Pages・Netlify・Vercel などの静的ホスティングに置けば、
スマホのブラウザから開けます。ホーム画面に追加すればアプリのように使えます。

APIキーはすべて Apps Script 側にあり、この `dist/` には含まれません。
ブラウザに保存されるのはウェブアプリURLと `API_TOKEN` だけです。
**共用端末では設定しないでください。**

## うまく動かないとき

| 症状 | 見るところ |
|---|---|
| 接続テストが失敗する | URLの末尾が `/exec` か／`API_TOKEN` が両側で一致しているか |
| 下書きが増えない | `log` シートのエラー／`batches` シートの `status`／Claude APIの残高 |
| 売上が0のまま | `log` シート／`REVENUE_SOURCES` の `query` がメールに実際にヒットするか |
| 投稿が failed になる | 承認画面にエラー文が出ます。トークンの期限切れが最も多い原因です |

Apps Script の **[実行数]** タブで、各トリガーの成功・失敗も確認できます。
