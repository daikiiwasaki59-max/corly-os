# 岩崎AIエージェント 土台設計 v1.0

作成日: 2026-09-11 / 状態: 段階0を構築済み。旧アプリは引き継がず白紙から再構築（岩崎指示）。

## 0. 結論
- AI会社の正体は「岩崎1人 ＋ 役職AI 5体 ＋ 共通の土台」。土台は ①憲法 ②会社知識 ③正データ ④承認ルール ⑤ツール接続。
- 技術は「Claude Code ＋ このリポジトリ ＋ コネクタ（Gmail / カレンダー / ドライブ / freee / Slack / Notion）」。月1〜2万円の上限は有料プランの範囲で収める想定（仮置き）。独自アプリと API 直叩きはやらない。
- 顧客への送信・請求発行・契約・LIOAS への送客連絡は AI の下書き止まり。実行は岩崎。自分だけで完結する行為（自分の予定・自分への通知・シート更新・下書き）は自動OK。
- 着手順: 土台 → 事務 → インサイド → 経理 → 経営幹部 → アウトサイド。

## 2. 5層アーキテクチャ
```
L4 入口   岩崎 ⇄ Claude Code（1本のチャット）＋ 定期実行（朝の1通・週次レビュー）
L3 役職   exec / inside-sales / outside-sales / accounting / admin（.claude/agents/）
L2 承認   自動OK / 岩崎承認 / 禁止（company/05_approval_policy.md）
L1 知識   憲法・商材・ICP・プレイブック・文面（company/）
L0 データ スプレッドシート「CORLY OS」＋ freee
接続: Gmail / カレンダー / ドライブ / freee / Slack / LINE（段階1）
```
原則: 正データは1か所。知識は平文で岩崎が直せる。役職はファイル1枚。外向き行動は全てログ（承認待ちシート）。

## 3. 役職（詳細は `.claude/agents/`）
| 役職 | 主な仕事 | 書き込み先 | 承認境界 |
|---|---|---|---|
| exec | 週次レビュー、停滞指摘、今週の一手、他役職の品質チェック | 承認待ち（提案） | 提案まで |
| inside-sales | リスト整備、初回文面、返信要約、追客、アポ候補、燃料送客候補 | 取引先・活動・承認待ち・Gmail下書き | 送信は岩崎 |
| outside-sales | 訪問パック、活動ログ化、日報下書き、見積下書き | 活動・案件・日報・見積 | 見積発行は岩崎 |
| accounting | 請求下書き、入金照合、督促文面、月次集計 | 請求・承認待ち・freee下書き | 確定登録・送付は岩崎 |
| admin | 朝の1通、期限リマインド、書類差し込み、ドライブ整理、会社知識への転記 | 承認待ち・company/ | 削除・共有・捺印は岩崎 |

## 4. 日常の入口（質問4「汎用性が高いのは」への回答）
**Claude Code（Web版 claude.ai/code）を推奨。** 理由:
- PC のブラウザ、デスクトップアプリ、スマホの Claude アプリから同じリポジトリ・同じコネクタで使える。
- 出力は全てスプレッドシートと LINE に落ちるので、チャットを開かなくても状態が見える。
- 独自アプリを作らないので、保守が岩崎1人に乗らない。
外出先はスマホの Claude アプリで「outside-sales、いま〇〇に行った、〇〇と言われた」と話すだけで活動ログになる。

## 5. データ（詳細は `company/06_data_schema.md`）
取引先1枚にステージで新規／見込みを区別。燃料の数千件も「事業」列で同居。価格表シートが唯一の価格の出所。承認待ちシートが全ての外向き行動の記録。

## 6. リスクと回避策（法務・税務は論点整理まで。最終確認は専門家へ）
| リスク | 回避策 |
|---|---|
| 個人情報保護法（顧客情報を AI へ渡す） | 必要な列のみ。数千件を丸ごと読ませない。購入リストは出所の規約を確認 |
| 特定電子メール法（営業メール） | フッターに事業者名・所在地・連絡先・受信拒否方法を固定。一斉送信なし。連絡NG は再送禁止 |
| LIOAS との委託契約 | 顧客情報の帰属・第三者サービス利用・競業避止を契約で確認してから AI に扱わせる |
| フリーランス新法 | CORLY が役員1名・従業員なし法人なら特定受託事業者に該当しうる。CORLY 側の権利として把握 |
| 揮発油等品確法 | 送客のみなら登録対象外が通常。CORLY 名義で契約・請求するなら要確認 |
| 信用毀損（価格・実績・法的表現の誤り） | 価格表と実績シート以外を書かない。法的断定は禁止。送信前に岩崎承認 |
| 会計誤登録 | freee は下書きまで。確定は岩崎。月次で税理士確認 |
| 反社チェック | 取引先シートに日付列。未実施で成約なら経理が警告 |
| 1人依存 | 承認待ちを毎朝1通に集約。1日1回見れば回る |
| 環境依存 | 知識とデータは平文とスプレッドシート。AI が止まっても業務は続く |

## 7. 予算の見方
- AI 利用料は Claude の有料プラン内で運用する前提（仮置き）。プラン料金は Anthropic の公式ページで確認する。API 直叩きは段階6以降まで使わない。
- 岩崎の週30〜40時間のうち、AI との往復（承認・入力・確認）は1日30分〜1時間を仮置き。残りは訪問・電話に充てる。
