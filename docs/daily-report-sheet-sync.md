# 日報 → スプレッドシート自動追記の設定方法

CORLY OS の「📝 日報」画面から送信した日報を、Google スプレッドシートに自動で1行ずつ追記できるようにする手順です。バックエンドサーバーを用意する必要はなく、Google Apps Script を使います。

## 1. スプレッドシートを用意する

1. Google スプレッドシートを新規作成する（既存のものでも可）
2. シート名はそのままで構いません（初回送信時にスクリプトが自動で「日報」シートを作成します）

## 2. Apps Script を設置する

1. スプレッドシートのメニューから [拡張機能] → [Apps Script] を開く
2. デフォルトで開いている `コード.gs`（`Code.gs`）の中身を全て削除する
3. このリポジトリの `apps-script/daily-report.gs` の内容をコピーして貼り付ける
4. 保存する（プロジェクト名は任意でよい）

## 3. ウェブアプリとして公開する

1. 右上の [デプロイ] → [新しいデプロイ] をクリック
2. 種類の選択（歯車アイコン）で「ウェブアプリ」を選ぶ
3. 「実行するユーザー」→ 自分（自分のアカウント）
4. 「アクセスできるユーザー」→ 全員
5. [デプロイ] をクリックし、権限の承認画面が出たら自分のGoogleアカウントで承認する
6. 発行された **ウェブアプリのURL** をコピーする
   - 例：`https://script.google.com/macros/s/XXXXXXXXXXXX/exec`

## 4. CORLY OS 側で接続する

1. CORLY OS の「📝 日報」画面を開く
2. 上部の「⚠️ スプレッドシート未接続」ボタンをタップして設定欄を開く
3. コピーしたウェブアプリのURLを貼り付ける（入力欄からフォーカスを外すと自動保存されます）
4. ボタンが「🔗 スプレッドシート連携：接続済み」に変われば設定完了です

## 5. 日報を入力して送信する

「今日の活動件数」（飛び込み訪問・電話架電・メール送信・DM送信・成約）と所感・明日のアクションを入力し、「📤 日報を記録する」を押すと、指定したスプレッドシートの「日報」シートに1行ずつ自動追記されます。

## 注意点

- Apps Script の CORS 制約により、送信結果（成功/失敗）を完全に判定することはできません。送信した日報はこの端末内（ブラウザの localStorage）にも保存されるため、あとから見返せます。
- ウェブアプリのURLはこの端末のブラウザ内にのみ保存され、外部やCORLY OSの提供元には送信されません。
- スプレッドシートを他人と共有すると、共有相手も内容を閲覧・編集できるようになります。共有設定には注意してください。
- Apps Script のコードを更新して「新しいデプロイ」を作成し直すと、URLが変わることがあります。その場合はCORLY OS側のURL設定も新しいURLに更新してください（同じデプロイを「編集」で更新すればURLは変わりません）。
