三本の商品

性格が違うので、役割も分ける

原状回復 一気通貫

庄栄興産の名前で営業。単価を上げる柱。

管理会社→岩崎＋福源屋→工務店＋大槻（清掃）
勝ち筋
同業（管理会社）が出す提案。「管理会社の立会を、管理会社が代行する」。工事業者と同じ単価勝負の土俵に乗らない。
商品
退去立会（有料）→ 原状回復工事 → 空室清掃 → 完了確認。立会は入口商品にもなる。
単価が上がる理由
下請けの1K美装 9,000円 に対し、管理会社直請けは 13,000円（実績値）。1次請けに入れば1Kでも上がる。
ターゲット
大阪の管理会社 204社（日管協名簿ほか）。
高 21社吹田13豊中7池田1中 60社
入り方
全部の切り替えは狙わない。「立会だけ」「繁忙期の溢れ分」「特定エリアだけ」で入り、結果を出して広げる。
取り分
工事の粗利から。清掃からは取らない。率は未登録（2分の1以上で交渉）。

清掃

今日から売れる唯一の商品。岩崎の取り分はゼロ。

管理会社／工事業者→大槻（清掃）
なぜ売るか
粗利は取らない。それでも売る理由は3つ。①大槻の稼働が埋まれば清掃事業に利益が残り、分配の余地が出る ②清掃で入って立会・工事に広げる入口になる ③価格表も実績も納品体制もあり、今日から売れる。
単価
管理会社 直請け：1K美装 13,000円／エアコン 9,000円。
工事業者の下請け：1K美装 8,000〜9,000円／エアコン 4,000〜4,500円（実績値）。
先に確認すること
大槻の空き稼働。月30〜50室 × 3〜5時間で、1人ならほぼ埋まっている可能性が高い（仮置き）。空きがないのに取ると外注に振るしかなく、粗利は5%しか残らない（実績値）。
空きがないときの手
量を増やさず 入れ替える。下請け9,000円を直請け13,000円にすると、同じ手間で1室4,000円増える。40室なら月16万円（仮置き）。
売ったあとの一言
「次の退去のときは、立会からお預かりすることもできます」。清掃単体で終わらせない。

配達給油

LIOAS の名前で営業。継続収入で足場を作る柱。

モリカワ商事（契約）→LIOAS 岩崎（窓口）→配送業者
勝ち筋
利益は 数量 × 取り分。件数より1件の数量。配送料が有利な大阪市内・阪神間に絞る。売っているのは油ではなく「給油所まで往復する時間」。
商品
軽油が基本。灯油・重油はエリア限定（実績値）。給油対象は 重機・トラック・ダンプ・クレーン・タンク。現在すでに実施中。
報酬
月間数量 × 1〜3円/L、翌月末振込（実績値）。1件あたり 10,000〜30,000L/月 が上限（実績値）。取り分2円なら 月2〜6万円/件。
ターゲット
建設・解体・産廃運送（10台〜）バス工場ボイラー
候補 42社 抽出済み。次は「自社の中間処理工場を持つ産廃業者」から当たる。重機が毎日同じ場所で動くので数量が読める。
向く顧客
①重機を自社保有 ②自家用給油設備がない ③稼働時間が給油所と合わない。この3つが揃う先。
触らない先
配送業者の既存顧客。接触前に必ず確認する。

60日でやること

2週間 × 4。走りながら直す
  1. W1–29/12–9/25
    譲渡契約の競業避止・秘密保持を弁護士に確認。庄栄興産と価格を決める（立会単価・工事単価表・保証期間・日数）。仮置きで先に進めてよい。
    灯油・重油の対応エリアを確認。配送業者の既存顧客の確認方法を決める。産廃業者から候補を広げる。
    大槻の空き稼働を確認する。いまの30〜50室の直請け／下請けの内訳を出す。空きがなければ、量ではなく単価の入れ替えを狙う。
    会社の所在地・電話・メールを登録。これがないとメールが1通も出せない。スプレッドシートを作る。
  2. W3–49/26–10/9
    提案書 v1。高優先21社のサイトから電話番号を埋める。初回接触を開始（1日2〜3通）。10/1 譲渡実行。
    大口候補へ初回接触を開始。
    21社への接触に「清掃だけでも」を必ず添える。同業2社に繁忙期の溢れ分を受けられると伝える。
    朝1通の通知（LINE）を動かす。承認の型を回す。
  3. W5–610/10–10/23
    商談4社。「立会だけお試し」で提案2社。自社管理物件で完了報告の見本を1室分撮る。
    商談3社、与信申請1件。
    数字で振り返り。効いた文面だけをプレイブックに残す。
  4. W7–910/24–11/10
    管理会社1社から継続発注を取る。賃貸住宅フェア大阪（11/26–27）の来場登録。
    大口2件（合計20,000L以上）を取る。
    接触→商談→提案の転換率を出し、次の60日を設計する。

60日の到達目標は 管理会社1社（継続）＋ 燃料の大口2件。これは50万円への通過点であって、到達点ではない。

やらないこと

  • 清掃単体で終わる営業。受けたら必ず立会・工事へ広げる一言を足す
  • 大槻の空きを確かめずに受けて、外注に振る（粗利が5%しか残らない）
  • 1日200件のテレアポ、FAX一斉送信、地図サービスからの機械的なリスト作成
  • 出所が説明できないリストの使用（カミックスのリストは使わない）
  • 配送業者の既存顧客への営業
  • 価格表にない金額を口頭で言う
  • オーナーへの直接営業で管理会社の頭越しをする
  • 他社批判、根拠のない保証、ガイドラインに反する負担区分の説明

効いてくるリスク

法務・税務は論点整理まで。最終確認は専門家へ

分配率が未定のまま営業が進む

書面化は不要という判断は尊重する。ただし最初の受注案件で「この案件の粗利がいくらで、岩崎にいくら」を実数で確認すること。そこで認識がずれたら書面にする。フリーランス新法では、発注者側が業務内容・報酬・支払期日をメール等で示す義務がある。メール1本が最低線。

譲渡契約の競業避止が岩崎個人を縛る可能性

会社法の競業避止は譲渡会社に及び、岩崎個人には直接及ばない。ただし契約書に代表者個人を縛る特約があれば別。10/1 前に条文を読む。

清算中の法人では新しい契約を結べない

清算中の会社は清算目的の範囲でしか活動できない。庄栄興産・LIOAS との契約と報酬の受け皿は個人事業に切り替える。請求名義と税務に直結する。

数字の出典が未検証

工事の受注額・粗利率・立会単価は、検索結果の要約から取った参考値。本文を1つも読めていない。提案書や採算表に載せる前に、庄栄興産の実数で置き換える。

燃料は Web に情報が出ない業界

配達給油を打ち出している配送業者を検索で1社も確認できなかった。実態はあるのに Web に出ていない。つまり競合も検索では見つからない。競合情報は岩崎の業界内の情報に頼る。

数字の区分は「実績値」か「仮置き」。出典が言えない数字は書かない。
