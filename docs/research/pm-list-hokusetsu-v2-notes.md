## 4. 取れなかった理由

1. **面の検索はポータル（SUUMO/アットホーム/ホームズ/goo）と集約サイト（カソット/フドーノ/エスタス管財の地域ページ）に吸われる。** 同じ9件が繰り返し返り、1回の検索で新規社名が1〜2件しか増えない。中盤以降は「会社名＋会社概要＋電話」の裏取りに検索を振り替えた。
2. **国交省の賃貸住宅管理業者検索・日管協会員一覧はスニペットに個社が出ない**（一覧ページのタイトルだけ返る）。管理業登録番号はニッケイ（登録あり・番号不明）、成都（大臣(2)000478）、前回のフドーノ由来2件しか取れていない。
3. **箕面・池田はスニペットで電話が出にくい**（地元の小規模店が多く、公式サイトの会社概要がインデックスされていない）。5＋4件中、電話は各2件。
4. **淀川区・北区は既存名簿に既に多い**（淀川13・北区30）ため新規は本社確認できた社に絞った。北区は「本社が北区」の裏が取れた新規が少なく2件のみ。
5. **管理戸数はスニペットに出た6社のみ**（成都14,600・掛谷2,789・エスタス3,600・賃貸大阪888・淀川住宅390・第一不動産は物件数192件）。大半の地場会社は公表していない。
6. 大手FC店（エイブル・ミニミニ・ハウスコム・東急リバブル等）は仲介中心のため除外。分譲管理のみ（浪速管理・大和ライフネクスト）も除外。
