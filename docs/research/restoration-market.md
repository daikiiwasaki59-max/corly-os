# 原状回復・空室清掃 市場調査（管理会社向けワンストップ営業の採算用参考値）

- 作成日: 2026-09-11
- 用途: 「庄栄興産」名義で管理会社向けに「退去立会 → 原状回復工事 → 空室清掃 → 完了確認」を一気通貫で営業する計画の採算試算に使う参考値
- 調査方法: Web検索（WebSearch）。**本セッションではページ本文の取得（WebFetch）が全ドメインでネットワーク遮断されたため、数字はすべて検索結果の要約・スニペットから取得したもの。ページ本文で裏取りできていない**。採算計算に使う前に、下記URLを岩崎が直接開いて数字を確認すること。信頼度はその前提で付けている。
- ルール: 数字はすべて「相場（幅）」＋出典URL。出典のない数字は書かない。社名は検索で確認できたものだけ。

---

## 結論（先に要点）

1. **1Kの原状回復（クロス・床・クリーニング込み、喫煙・過失なしの標準）は 7〜10万円、1LDKは 10〜15万円、2LDKは 15〜23万円が全国目安**（出典①-A）。大阪の業者情報では「1K/1DKの基本クリーニング 3〜5万円＋クロス900〜1,200円/㎡加算」（出典①-C）と、大阪はやや安めに出る。
2. **元請けの粗利は 25〜35%、中間マージンは 20〜30%（最大40%）が一般的**。原状回復工事は内装工事の中で最も利益率が高い部類（30〜50%）とする業界記事あり（出典②-A, ②-B, ②-D）。ただし内装工事業の平均粗利は20〜30%、建設業全体は約23〜24%（出典②-E, ②-F）。**採算試算の仮置きは「工事原価率 65〜75%（粗利25〜35%）」が妥当**。
3. **退去立会代行の管理会社向け公開価格は 9,000〜15,000円/回（税別）**。大阪の業者は 9,000円（継続取引）、10,000円、15,000円〜。**工事セットなら無料・値引きが業界の定石**（出典③-A〜③-E）。
4. **空室清掃 1K は 15,000〜30,000円 が相場**。大阪（堺）の法人向け業者で 18,000円（税込19,800円、27㎡まで）の公開例（出典④-A〜④-E）。
5. **管理会社が業者を選ぶ軸は「着工スピード（空室期間）」「自社施工体制」「立会〜工事〜清掃のワンストップ」「写真付き報告書」「手直し保証」「数量×単価の透明な見積」**（出典⑤-A〜⑤-D）。これは本計画の売り文句と一致する。
6. **国交省ガイドライン**: 通常損耗・経年変化は貸主負担、故意過失・善管注意義務違反は借主負担。クロスは耐用年数6年で残存価値1円。特約は「必要性・合理性」「借主の認識」「暴利的でない」が有効要件（出典⑥-A〜⑥-E）。**営業トークで「退去者に全額請求できる」系の説明は絶対にしない**。
7. **北摂・大阪市内で管理会社向けワンストップを打ち出す競合**: 合同会社eima（吹田）、株式会社ワイズホーム（豊中）、株式会社ダスノン（大阪市中央区・北摂対応）、株式会社アルファリフォーム（大阪市生野区・北摂対応）、株式会社NEOSCOPE（大阪市中央区）。公開価格があるのはダスノン（立会15,000円〜）とNEOSCOPE（クロス700〜750円/m）（出典⑦）。

## 5. 管理会社が原状回復業者を選ぶ基準

## 6. 国土交通省「原状回復をめぐるトラブルとガイドライン」の要点（営業トーク用）

一次資料: 国交省ページ https://www.mlit.go.jp/jutakukentiku/house/jutakukentiku_house_tk3_000020.html 、再改訂版本文PDF https://www.mlit.go.jp/jutakukentiku/house/torikumi/honbun2.pdf 、Q&A https://www.mlit.go.jp/jutakukentiku/house/jutakukentiku_house_tk3_000024.html 、参考資料（令和5年3月） https://www.mlit.go.jp/jutakukentiku/house/content/001611293.pdf

| 要点 | 内容 | 出典 |
|---|---|---|
| 原状回復の定義 | 借主の故意・過失、善管注意義務違反、その他通常の使用を超える使用による損耗・毀損を復旧すること。**経年変化・通常損耗は借主に求めない** | 出典⑥-A, ⑥-B |
| 民法改正（2020年）で明文化 | 通常損耗・経年変化は借主の原状回復義務に含まれない（民法621条） | 出典⑥-A |
| 貸主負担の例 | 家具設置による床のへこみ、日照によるクロス変色、画鋲の穴、通常使用でのエアコン設置跡（特約がない場合） | 出典⑥-B, ⑥-C |
| 借主負担の例 | タバコのヤニ・臭い、ペットの傷・臭い、引越し作業の傷、手入れ不足のカビ・水垢、結露放置のシミ | 出典⑥-B, ⑥-C |
| 損耗の区分 | A（通常損耗・経年変化＝貸主）、A(+G)（グレードアップ＝貸主）、B（借主の故意過失等＝借主）、A(+B)（通常使用でも手入れ不足で拡大＝借主） | 出典⑥-B |
| 経過年数の考慮 | 借主負担でも経過年数で減価。クロス・カーペット・クッションフロアは耐用年数6年、6年で残存価値1円。計算式 (耐用年数−経過年数)÷耐用年数。例: 入居3年で退去なら残存50%、4万円のクロス工事の借主負担は2万円 | 出典⑥-D |
| 施工単位 | 借主負担でも「毀損部分の補修」が原則（クロスは㎡単位、色合わせで最低限の面積）。1室全面を当然に借主負担にはできない | 出典⑥-B |
| 特約の有効要件 | ①特約の必要性があり暴利的でないなど客観的合理的理由がある ②借主が通常の原状回復義務を超える負担を認識している ③借主が特約による義務負担の意思表示をしている | 出典⑥-E |
| ガイドラインの位置づけ | 強制力はなく、契約内容・使用状況で個別判断。ただし紛争時の基準として広く参照される | 出典⑥-A |
| 最高裁判例の考え方 | 通常損耗の減価回収は賃料に含まれているのが通常（通常損耗を借主負担とする特約は明確な合意が必要） | 出典⑥-E |

- 出典⑥-A: https://www.mlit.go.jp/jutakukentiku/house/jutakukentiku_house_tk3_000020.html / https://www.jpm.jp/topics/49507
- 出典⑥-B: https://www.initialagency.co.jp/restoration/blog/genjokaifuku-guideline/ / https://www.initialagency.co.jp/restoration/blog/burden-ratio-table/
- 出典⑥-C: https://urashico2.com/blog/restoration_guidlines/ / https://rv21.jp/blog/6514
- 出典⑥-D: https://chintai-reform-lab.jp/genjo-kaifuku/guideline-useful-life/ / https://bc-kouji.com/blog/20250715-39/ / https://amaze2016.com/media/4213/
- 出典⑥-E: https://chintaidx.com/media/2022012701_01/ / https://miyakoanshinsumai.com/column/column-15600/ / https://rcaa.or.jp/insight/genjokaifuku-guideline-civil-law/

**営業トークで言ってはいけないこと（上記から導出）**
- 「クロス全面張替を退去者に全額請求できる」→ 誤り。㎡単位・経過年数減価が原則。
- 「6年以上住んだ人でもクロス代は取れる」→ 誤り。残存価値1円。ただし故意過失で「張替工事の施工に必要な費用の一部（工賃等）」を負担させる余地はあるため、断定せず「ガイドライン上は原則取れない」と説明。
- 「特約があれば何でも借主負担」→ 誤り。有効要件を満たさない特約は無効になり得る。
- 管理会社に対しては「立会時にガイドライン準拠で借主・貸主負担を切り分け、写真と精算根拠を残す」ことを価値として売る。**法務の最終確認は専門家へ**。
