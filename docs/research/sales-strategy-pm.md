## 0. 結論（先に読む）

1. **売る相手は「立会と工事を丸ごと投げたい小〜中規模の管理会社」**。管理会社が原状回復業者に求めるのは、空室期間の短縮（立会翌日見積・承認後即着工）、ワンストップ、写真つき報告、手直し保証、ガイドライン準拠の説明ができること（§1）。
2. **勝ち筋は「同業（管理会社）が出す提案」**。庄栄興産は管理会社なので、「管理会社の立会を管理会社が代行する」＝ 現場の言葉が通じる、入居者・オーナー説明の型を持っている、という差別化が出せる。工事業者の営業と同じ土俵（単価勝負）に乗らない。
3. **決裁者は小規模なら社長、中規模なら管理部（または工事課）の責任者**。入口は紹介 → 業界団体（宅建協会 北摂支部・日管協 大阪府支部）→ 展示会（賃貸住宅フェア大阪 11/26–27）→ メール、の順（§2）。
4. **価格の見せ方は「立会は工事とセットで0円 or 定額、工事は間取り別パック＋単価表」**が先行事業者の型（§3）。庄栄興産の実数（工事受注額・工務店発注額・立会単価）が未登録なので、価格表は S2 までに岩崎が埋める。
5. **実績が少ない段階は「体制・流れ・報告書の見本」で信頼を作る**。提案書に完了報告書のサンプル（写真＋負担区分）を1室分入れる（§4）。
6. **見込み客リストは国交省の検索システム・大阪府の名簿・業界団体の会員検索・自社サイトから作る**。地図サービスのスクレイピングはやらない（§7）。

## 1. 管理会社の業務と意思決定

### 1-1. 退去〜原状回復〜募集の流れ（一般形）
| 段階 | 内容 | 管理会社の関心 |
|---|---|---|
| 解約受付 | 入居者から解約通知。退去日と立会日を調整 | 立会の人繰り |
| 退去立会 | 管理会社（または貸主）と借主が室内で損耗を共同確認。借主の負担範囲を確定する場面 | 入居者との揉め事回避、ガイドラインに沿った説明 |
| 見積・負担区分 | 借主負担 / 貸主（オーナー）負担を分けて見積。敷金精算書を作る | 見積の速さ、オーナーへの説明材料 |
| オーナー承認 | 貸主負担分の工事をオーナーに提案・承認 | 写真つきで説明できる資料 |
| 工事・清掃 | クロス・CF・設備補修 → 清掃 | 工期、手直しの少なさ |
| 完了確認・募集 | 完了確認後に募集（内見可能に） | 退去から募集開始までの日数（＝空室期間） |

出典:
- 退去立会の定義・流れ: イニシャルエージェンシー「退去立会とは？」 https://www.initialagency.co.jp/restoration/blog/move-out/ （立会は「借主の責任範囲を確定する重要な場面」、社内対応と外注対応の2方式）
- 「立会翌日に見積 → 承認後即着工で、立会業者から施工業者への引き継ぎ待ちがゼロ、退去から募集開始までのリードタイム最短」: 同社 https://www.initialagency.co.jp/restoration/blog/tokyo-restoration/
- 「立会・解約精算 → 原状回復・リフォームまで一貫で次の入居までのスケジュール短縮」: リビングステージ https://livingstage.info/service/taikyotachiai/
- 管理会社の業務実態（社内対応はベテラン社員が対応するケースが大半、スタッフ育成が課題）: 全国賃貸住宅新聞 https://www.zenchin.com/news/post-8034.php
- 管理会社の業務範囲（維持保全・集金・契約更新解約・退去後の清掃業者手配と原状回復）: 日管協「賃貸住宅管理業とは」 https://www.jpm.jp/outline/rent_mgmt.html 、イエコン https://iekon.jp/column/investment/17537

- 参考値（仮置き）: 消費生活センターへの賃貸トラブル相談は年3〜4万件、うち敷金・原状回復が3〜4割（出典: 国交省ガイドラインページ https://www.mlit.go.jp/jutakukentiku/house/jutakukentiku_house_tk3_000020.html ）。

### 1-3. 岩崎の提案に効く「管理会社の痛み」
- 立会はベテラン任せで属人化、育成できない（§1-1 全国賃貸住宅新聞）。→ 「立会ごと預かる」が刺さる。
- 業者を分けると引き継ぎ待ちで空室が延びる（§1-1 イニシャル）。→ 「立会翌日見積・承認後すぐ着工」を流れとして見せる。
- 入居者クレームとオーナー説明の両方が面倒。→ 「写真つき負担区分表」と「オーナー向け完了報告」を標準納品にする。

**型として抜き出せること**
1. メニューは必ず「立会 → 工事 → 清掃（→ 入居後修繕）」の順で並べ、「一括」「ワンストップ」を見出しにする。
2. 価格は3層: ①立会代行の定額（0円〜15,000円。工事セットで無料 or 値引き）、②工事は平米単価表（クロス・CF）＋間取り別の目安、③清掃は間取り別定額（庄栄興産は `01_products.md` の価格表①が使える）。
3. 「ガイドライン準拠」「写真・書面のエビデンス」「敷金精算書まで作る」を報告の形として明記する。
4. 保証は「手直し保証（期間を明記）」。期間は一般に1年程度が目安（ https://rv21.jp/blog/6413 ）。**庄栄興産の保証期間は工務店と合意してから書く（未登録）。**
5. 実績は「件数」か「対応エリア・最短日数」で示す。件数が少ない場合は後者。

## 6. やらないこと・危険なトーク

### 6-1. やらないこと（`company/07_strategy.md` と整合）
- 清掃単体の飛び込み。管理会社の「清掃業者リスト」「協力会社登録」に入るだけの営業。
- 1日200件のテレアポ、FAX一斉送信、地図サービスからの機械的なリスト作成（§7）。
- 価格表にない金額を口頭で言う（`01_products.md` 未登録の工事・立会単価は「お見積りで」と答える）。
- オーナーへの直接営業で管理会社の頭越しをする（管理会社が発注権限を持つ。§2-1）。
- 未確認の紹介者名を使う。

### 6-2. 危険なトーク（法令・信用）
| 危険なトーク | なぜ危ないか | 言い換え |
|---|---|---|
| 「退去者からしっかり取ります」「敷金は返しません」 | 国交省ガイドラインは通常損耗・経年変化は貸主負担、改正民法（2020年施行）も借主は通常損耗の原状回復義務を負わないと明文化。負担割合の逆転は返還請求・消費者トラブルの元 | 「ガイドラインに沿って負担区分を写真つきで整理し、入居者にもオーナーにも説明できる形にします」 |
| 「クロスは全面貼替で借主負担」 | ガイドラインは経過年数による減価（耐用年数）と、補修は「毀損部分を含む最小単位」が原則 | 「借主負担分は経過年数を反映して算定します」 |
| 「特約で全部借主負担にできます」 | 特約が有効となる要件（必要性・合理性、借主が認識し合意）が厳しい。法的助言は専門家へ | 「特約の有効性は契約書次第なので、判断は御社・専門家に。私たちは事実の記録を出します」 |
| 他社批判（「〇〇社は高い/雑」） | 信用リスク・不正競争防止法の論点（`03_playbook.md`） | 自社の流れと報告の形だけ話す |
| 「絶対に〇日で終わる」「一切クレームは出ない」 | 根拠のない保証。工務店の繁忙・資材で変動 | 「標準の日数は {n} 日。遅れる場合は着工前に連絡します」 |
| 「業界平均の空室期間は〇か月なので〇万円損しています」 | 出典が言えない数字、相手の実数ではない | 「御社の退去から募集開始までの日数を教えてください。そこを縮める提案をします」 |
| 「建設業許可がなくても大丈夫」 | 工事金額・内容によって許可の要否が変わる（論点整理まで。最終確認は専門家へ） | 協力工務店の許可・保険を提案書に明記する |

出典: 国交省「原状回復をめぐるトラブルとガイドライン」 https://www.mlit.go.jp/jutakukentiku/house/jutakukentiku_house_tk3_000020.html （本文PDF https://www.mlit.go.jp/jutakukentiku/house/torikumi/honbun2.pdf 、参考資料 令和5年3月 https://www.mlit.go.jp/jutakukentiku/house/content/001611293.pdf ）、改正民法の明文化: https://vs-group.jp/lawyer/tachinoki/rent/saikaitei/ 。**法務・税務・許認可は論点整理まで。最終確認は専門家へ。**
