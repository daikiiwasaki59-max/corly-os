# CORLY OS のしくみ

## 1行でいうと

**AI社員が書く → 社長が承認する → 自動で投稿される → 売上が自動で集まる → 報告が上がる**
このループを1日単位で回し続けるのが CORLY OS です。

## 全体像

                      ┌──────────────────────────────┐

   執筆を指示 ────────▶│  各部のAI社員が下書きを書く      │
                      └───────────────┬──────────────┘
                                      │ ②10分おきに回収
                                      ▼
┌──────────────┐   ③承認   ┌──────────────────────┐
│  ダッシュボード │◀────────▶│  スプレッドシート (DB)  │
│  (React/PWA)  │           │  drafts / revenue     │
└──────────────┘           │  feed / ticker / log  │
        ▲                   └───────────┬──────────┘
        │ ⑥表示                          │ ④15分おき
        │                                ▼
        │                    ┌──────────────────────┐
        │                    │  X / Threads / WP へ  │
        │                    │  承認済みだけを投稿    │
        │                    └──────────────────────┘

## なぜこの構成なのか

### サーバーを立てない

常時稼働のサーバーを持つと、月額費用と運用（証明書・監視・アップデート）が発生します。
CORLY OS は **Google Apps Script** をバックエンドにしているため、

- サーバー費用ゼロ
- cron（時間トリガー）が標準で使える
- スプレッドシートがそのまま DB になり、中身を目視で直せる
- Gmail を標準ライブラリで読める（ASPの成果メールを取り込める）

という条件が揃います。個人〜数人規模の自動収益事業には十分です。

### なぜ Claude を「バッチ」で呼ぶのか

Apps Script の外部通信（`UrlFetchApp`）は **約60秒で打ち切られます**。
記事1本を同期生成させると、この上限を超えて失敗します。

そこで Message Batches API を使い、

1. `submitAgentBatch()` … 全部署ぶんの執筆依頼をまとめて投げる（即座に返る）
2. `pollAgentBatches()` … 10分おきに「終わった？」と確認し、終わっていれば回収

の2段構えにしています。タイムアウトを構造的に回避でき、
副次的にバッチ料金（同期実行の50%）になります。

### なぜ「承認」を挟むのか

技術的には全自動投稿も可能です。しかし挟むべき理由が3つあります。

1. **規約** — 多くのSNSは無審査の自動大量投稿を制限しています。人の確認が入る運用は規約上も説明がつきます。
2. **信用** — 事実誤認や不適切な表現が無審査で出ると、アカウントごと失います。取り返しがつきません。
3. **法令** — アフィリエイトはステマ規制・景表法の対象です。「PR表記があるか」の最終確認は人が持つべきです。

承認は1タップです。社長の仕事は画像と同じく「報告を聞いて、承認する」だけになります。

## データの流れ（シート構成）

| シート | 役割 |
|---|---|
| `drafts` | AIが書いた下書き。`draft → approved → published` と状態が進む |
| `revenue` | 売上1件＝1行。ここが集計の唯一の正 |
| `feed` | 報告グループのチャット。監督AIと各部AIの発言 |
| `ticker` | 画面下に流れる稼働ログ |
| `batches` | 投げたバッチの進行状況 |
| `log` | エラー記録。動かないときは最初にここを見る |

## 拡張するとき

| やりたいこと | 触る場所 |
|---|---|
| 部署を増やす | `src/config/company.js` と `backend/gas/00_Config.gs` の両方に同じ `id` で追加 |
| AI社員の書き方を変える | `00_Config.gs` の `brief` |
| 会社共通の編集方針を変える | `03_Agents.gs` の `HOUSE_RULES` |
| 投稿先を増やす | `04_Publish.gs` の `PUBLISHERS` に1関数追加 |
| 売上の取り込み元を増やす | `00_Config.gs` の `REVENUE_SOURCES` に1行追加 |
| 時間割を変える | `07_Triggers.gs` を編集して `installTriggers` を再実行 |
