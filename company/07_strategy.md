# 07 戦略書 v0.1（案）— 60日計画

作成日: 2026-09-11 / 状態: **岩崎の確認待ち**。2週間スプリント × 4。走りながら修正する。
前提の未確定事項（§6）が埋まると数字が変わる。

## 1. 結論
- **主戦場は清掃ではなく「管理会社向けの原状回復 一気通貫」**。庄栄興産の名前で「退去立会 → 原状回復工事 → 清掃 → 完了確認」を売る。清掃単体の営業はやめる。
- **燃料は固定費ゼロの積み上げ**。大阪市内・阪神間の大口（月 10,000L 級）に絞り、件数より1件の数量を追う。60日の指標は成約ではなく「商談数・与信申請数」。
- **岩崎の時間配分（仮置き）**: 営業 6割（管理会社 4 : 燃料 2）、経営・AI運用 2割、譲渡・契約整備 2割（S1〜S2 のみ）。
- 離脱ライン 300万円/月は燃料単独では届かない（§2）。清掃・原状回復側の利益構造が決め手。

## 2. ゴールの試算（全て岩崎回答の数字から。仮置き）
### 燃料
```
取り分 2円/L（1〜3円の中央。仮置き）
現在:   3〜5万円/月 ≒ 1.5〜2.5万 L/月
月30万円 = 15万 L  = 大口(10,000L) 15件 or 標準(2,500L) 60件
月300万円 = 150万 L = 大口 150件   ← 燃料単独では非現実的
```
→ 12か月の燃料目標は「月 20〜30万円（大口 10〜15件）」を仮置き。岩崎が置き直す。

### 清掃・原状回復
```
譲渡後の清掃売上 70〜80万円/月、外注費 21万円/月、材料 1.5〜10万円/月（30〜50室 × 500〜2,000円）
大槻の人件費: 未登録 → 清掃の利益は計算不能
原状回復工事の1室あたり受注額と工務店への発注額: 未登録 → 一気通貫の利益は計算不能
明細書の外注案件: 売上 206,400円 / 外注 196,080円 / 粗利 10,320円（粗利率 5%）
```
→ 現状の構造では外注に振るほど利益が消える。単価を上げられる直請け・一気通貫に移らないと「外注に振れる」状態にならない。
→ **§6 の未確定 3 点が埋まるまで、12か月の利益目標は置かない。**

## 4. 事業別の戦略
### 4-1. 清掃・原状回復（庄栄興産名義）
**勝ち筋**: 管理会社が最初に投げたい相手は「立会と工事ができる業者」。庄栄興産の名前でその層に入る。清掃は付属にする。

**階段**
| ステージ | 立ち位置 | 期間 | 完了条件 |
|---|---|---|---|
| 0 | 清掃単体の下請け（今） | — | — |
| 1 | 庄栄興産名義で「一気通貫」を小規模管理会社へ提案。工事は協力工務店へ委託 | 60日 | 一気通貫の受注 1件、提案書と価格表が固まる |
| 2 | 立会・工事・清掃・完了確認の型を回し、外注に振っても利益が残る単価にする | 3〜6か月 | 月次粗利で外注比率を上げても利益が増える |
| 3 | 管理戸数の多い管理会社と継続契約。現場は大槻＋外注、岩崎は営業のみ | 6〜12か月 | 岩崎が現場に出ない月が続く |

**TTP（徹底的にパクる）の対象**: 1〜2段上の「大阪で管理会社直請けの原状回復を回している中小事業者」。実在企業は Web 検索で出典つきで exec が候補を出す（S1）。真似る対象は「提案書の構成・価格の見せ方・完了報告の形」。

**やらないこと**: 清掃単体の飛び込み。管理会社の「清掃業者リスト」に入る営業。

### 4-2. 燃料（LIOAS 岩崎名義）
**勝ち筋**: 利益 ＝ 数量 × 取り分。配送料の安い大阪市内・阪神間で、月 10,000L 級の先に、価格差 3〜5円 で提案。

**工程**: 大口候補の選別（AI）→ 協力業者6社の顧客でないことを確認 → 紹介ルートの有無を確認（大栄環境型）→ 初回接触（承認）→ 商談 → 与信申請 → モリカワ商事と契約 → 毎月の単価設定と数量の照合（経理）。

**やらないこと**: 小口の数集め。協力業者の顧客への接触。出所が説明できないリストの使用。
