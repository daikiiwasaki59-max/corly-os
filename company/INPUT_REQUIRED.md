# 岩崎の入力待ち項目（段階0を動かすために必要）

埋まるまで、エージェントは該当項目を「未登録」と書く。推測で埋めない。
回答はこのファイルに直接書くか、Claude に「〇〇は△△」と伝えれば、事務エージェントが該当ファイルへ転記する。

## 1. 会社の基本（メールフッター・書類に使う）
- [ ] 会社所在地
- [ ] 代表電話
- [ ] 代表メールアドレス
- [ ] 請求用の振込先（請求書に載せる。AIは支払いには触れない）

## 2. 清掃（`01_products.md`）
- [ ] メニューと単価（商材名 / 単価 / 単位 / 原価 / 条件）
- [ ] 契約条件（最低契約期間・解約予告・支払サイト・請求タイミング）
- [ ] 提供エリア
- [ ] 導入実績（業種・件数。文面に使ってよい範囲）

## 3. 燃料（`01_products.md`）
- [ ] 取扱燃料の種類
- [ ] CORLY の報酬体系（成果報酬 / 固定 / 混合、単価、確定条件、支払時期）
- [ ] 顧客に言ってよい内容の範囲（LIOAS 承認済みの紹介文・NG表現）
- [ ] 委託契約書の所在（ドライブURL等）
- [ ] 送客の手順（LIOAS の誰に、何を、どう渡すか）

## 4. 対象顧客像（`02_icp.md`）
- [ ] 清掃: 対象業種の優先順・商圏・決裁者・入口の型・良い顧客の条件・避ける顧客
- [ ] 燃料: 燃料用途・対象業種・商圏・決裁者・良い顧客の条件
- [ ] 燃料リストの出所（自作 / 購入 / LIOAS 提供）と、個人名を含むか
- [ ] 現在のリストの現物の場所（Excel / スプレッドシート / 紙）

## 5. 目標（`00_charter.md`）
- [ ] 月の利益目標
- [ ] 清掃: 月の新規成約目標
- [ ] 燃料: 月の送客件数目標
- [ ] 1日の活動目標（訪問・架電・メール・DM・フォロー）

## 6. ツール
- [ ] スプレッドシート「CORLY OS」のURL（`setup-sheets.gs` 実行後）
- [ ] freee で使っている機能（会計 / 請求書）と会社ID
- [ ] LINE 公式アカウント（段階1で作成。Messaging API のチャネルトークンは Apps Script のプロパティに保存し、リポジトリには置かない）
- [ ] Google ドライブの書類フォルダ（契約書・見積ひな形の場所）
