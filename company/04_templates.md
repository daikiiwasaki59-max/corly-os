# 04 文面テンプレート

出典: `docs/research/sales-strategy-pm.md` §5。**{ } は差し込み欄。埋めずに送らない。**

## 固定ルール（全チャネル共通）
1. 差出人を明記。管理会社向けは「庄栄興産 岩崎」、燃料は「LIOAS 岩崎」。
2. メールには **事業者名・所在地・連絡先・受信拒否の方法** を必ず入れる（特定電子メール法の表示義務）。
3. 受信拒否の意思表示があった先へは再送しない。取引先シートの「連絡NG」を立てる。
4. **1通目に価格・実績の数字を入れない。** 2通目以降、相手の質問に応じて `01_products.md` の登録値のみ回答。
5. 一斉送信はしない。1通ずつ承認待ちシートに載せ、岩崎承認後に送る。
6. 未確認の紹介者名を使わない。紹介者の名前を出す許可を先に取る。
7. 燃料の文面で、価格・供給条件・品質を岩崎が約束する表現を使わない。

## 1. 管理会社への初回メール
```
件名: 退去立会〜原状回復〜清掃の一括対応のご案内（豊中・管理会社 庄栄興産）

{会社名} {部署名} {担当者名} 様

はじめてご連絡いたします。豊中市で賃貸管理を行っております庄栄興産の岩崎と申します。
{紹介者名} より、{会社名} 様が {地域} で管理をされていると伺い、ご連絡いたしました。

当社は自社の管理物件で行っている「退去立会 → 原状回復工事 → 空室清掃 → 完了確認」を、
同業の管理会社様向けにまとめてお預かりしております。
立会は国土交通省のガイドラインに沿って写真と負担区分をその場で記録し、
オーナー様にそのまま提出できる形で報告いたします。

「立会だけ」「繁忙期の一部だけ」からでもお受けしています。
一度、{会社名} 様の退去時の流れをお聞かせいただけないでしょうか。
{候補日1} / {候補日2} のいずれか、または {会社名} 様のご都合の良い日時で伺います。

（フッター）
```
紹介がない場合の3行目の差し替え:
```
{会社名} 様の {Webサイトで見た管理エリア・物件種別} を拝見し、ご連絡いたしました。
```

送信前チェック: ①宛先が連絡NGでない ②紹介者名を使う許可がある ③**数字がゼロ** ④フッターがある。

## 3. 訪問時の30秒トーク
```
豊中で賃貸管理をしている庄栄興産の岩崎です。
うちも管理会社なので、退去の立会と、その後の工事・清掃を自分たちで回しているのですが、
同じことを {地域} の管理会社さんの分もお預かりしています。
立会に写真と負担区分をつけて、オーナーさんにそのまま出せる報告にしているのが特徴です。
今、立会や工事の手配で一番手間になっていることはどこですか？
```
聞く順: ①月の退去件数 ②立会は誰が出ているか ③工事・清掃は何社に分けているか ④困りごと。
出口: 「次の退去1件、立会だけ試しに」＋ 名刺 ＋ 提案書は後日メール。

## 4. 紹介依頼（既存取引先・オーナー・工務店へ）
```
{相手の名前} さん、ひとつお願いがあります。
退去の立会から工事・清掃までを、管理会社さんの代わりにまとめて預かる仕事を始めました。
「立会の人手が足りない」「業者を分けていて空室が延びる」と言っている管理会社さんをご存じでしたら、
一社だけご紹介いただけませんか。ご紹介いただいた先には、{相手の名前} さんのお名前を出してよいですか？
```
紹介の謝礼は未登録。渡す場合は岩崎が決める（`05_approval_policy.md`）。
