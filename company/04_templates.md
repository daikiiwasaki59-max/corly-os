# 04 文面テンプレート

**本文は未整備。** 固定ルールと骨組みだけ先に決める。本文は岩崎の初回文面を元にインサイド営業エージェントが起こし、岩崎が「採用」したものをここに載せる。

## 固定ルール（全チャネル）
1. 差出人は「株式会社CORLY 岩崎」を明記。
2. メールには **事業者名・所在地・連絡先・受信拒否の方法** を必ず入れる（特定電子メール法の表示義務）。
3. 受信拒否の意思表示があった先へは再送しない。取引先シートの「連絡NG」を立てる。
4. 価格・無料条件・認証・補助金・実績は `01_products.md` に登録済みの内容以外書かない。
5. 一斉送信はしない。1通ずつ承認待ちシートに載せ、岩崎承認後に送る。
6. 燃料の文面では、価格・供給条件・品質を CORLY が約束する表現を使わない。

## メール共通フッター（必須）
```
株式会社CORLY 代表取締役 岩崎
所在地：{会社所在地}
電話：{電話番号}　メール：{メールアドレス}
※本メールの配信停止をご希望の場合は、本メールにその旨ご返信ください。以後お送りしません。
```

## 骨組み
| 用途 | 構成 |
|---|---|
| 初回メール | 宛名 → 名乗り → 連絡した理由（相手固有の1行） → 提案の核（1〜2行） → 依頼（15分の面談、候補日） → フッター |
| 初回DM（Instagram / X） | 名乗り → 相手固有の1行 → 提案の核 → 依頼（返信 or 10分） |
| フォロー（返信なし） | 前回送付の言及 → 補足の1行 → 依頼 → フッター |
| 督促（1回目） | 請求書番号・金額・期日 → 行き違いの断り → 状況確認の依頼 → 連絡先 |
| 燃料の送客案内 | 名乗り → LIOAS の紹介（LIOAS 承認済み文言のみ） → 依頼（LIOAS からの連絡可否） → フッター |
