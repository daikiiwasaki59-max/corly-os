## 活動の型（全事業共通）
- ステージ: 未接触 → 初回接触 → 提案済 → 交渉中 → 成約 / 失注
- チャネル: 飛び込み / 電話 / メール / LINE / Instagram / X / 紹介 / Web問い合わせ
- 活動結果: 会えた・話した / 留守・不在 / 折り返し依頼 / 資料送付済 / DM送信済 / 断られた
- 失注理由: 価格 / 時期 / 既存契約 / 不要 / 不明（1語で残す）

## 集め方
- 岩崎が訪問後に「〇〇に行った、こう言われた、こう返した」と話す → アウトサイド営業エージェントが活動ログに記録し、有効だった返しをこのファイルの候補として提案する。
- 岩崎が「採用」と言った返しだけを表に載せる。
