## A. 管理会社向け「原状回復 一気通貫」

### A-1. 勝ち筋（1行）
**同業（管理会社）が出す提案。** 庄栄興産は豊中の管理会社なので「管理会社の立会を管理会社が代行する」と言える。工事業者と同じ単価勝負の土俵に乗らない。

### A-2. 相手の痛み → こちらの一言
| 相手の痛み | 根拠 | 刺す一言 |
|---|---|---|
| 立会がベテラン任せで属人化。育成できない | 全国賃貸住宅新聞（`research/sales-strategy-pm.md` §1-1） | 「立会ごと預かります」 |
| 業者を分けているので引き継ぎ待ちで空室が延びる | 同 §1-1 | 「立会の翌日に見積、承認後すぐ着工まで一本です」 |
| 入居者クレームとオーナー説明の二重負担 | 同 §1-3 | 「写真つきの負担区分表と、オーナーにそのまま出せる完了報告を標準で付けます」 |

### A-3. 差別化の3点（提案書の3ページ目）
1. 同業なので現場の言葉が通じる。入居者・オーナー説明の型を持っている。
2. 立会 → 工事 → 清掃 → 完了確認を一本で預かる。引き継ぎロスがない。
3. 国交省ガイドラインに沿って写真と負担区分をその場で記録する。

### A-4. 入り方（重要）
**いきなり全部の切り替えを狙わない。** 既存業者との関係を切る話になるため通りにくい。入口は3つ。
- 「立会だけ」お試し
- 「繁忙期の溢れ分だけ」
- 「特定エリアの物件だけ」
出口の一言は **「次の退去1件を、立会だけでもお預かりします」**。

### A-5. 商談で聞く順（4つ）
1. 月の退去件数はどれくらいか
2. 立会は誰が出ているか（社内 / 外注 / 社長）
3. 工事と清掃は何社に分けているか
4. いま一番手間になっているのはどこか

### A-6. 決裁者
| 規模 | 決める人 |
|---|---|
| 小規模（社長＋数名） | 社長。立会も社長や店長が出ることがある |
| 中規模（管理部あり） | 管理部または工事課の責任者 |
| 仲介兼業の店舗型 | 店長が実務、社長が業者変更を決裁（仮置き） |

管理会社はオーナーに代わって工事範囲の指定と発注を行う。**管理会社に入ればオーナー個別営業は不要。オーナーへの頭越し営業はしない。**

### A-7. 危険なトーク（絶対に言わない）
| 言ってはいけない | 言い換え |
|---|---|
| 「退去者からしっかり取ります」「敷金は返しません」 | 「ガイドラインに沿って負担区分を写真つきで整理し、入居者にもオーナーにも説明できる形にします」 |
| 「クロスは全面貼替で借主負担」 | 「借主負担分は経過年数を反映して算定します」 |
| 「特約で全部借主負担にできます」 | 「特約の有効性は契約書次第なので判断は御社と専門家に。私たちは事実の記録を出します」 |
| 他社批判（「〇〇社は高い/雑」） | 自社の流れと報告の形だけ話す |
| 「絶対に〇日で終わる」「クレームは一切出ない」 | 「標準の日数は {n} 日。遅れる場合は着工前に連絡します」 |
| 「業界平均の空室期間は〇か月なので〇万円損しています」 | 「御社の退去から募集開始までの日数を教えてください。そこを縮める提案をします」 |
| 「建設業許可がなくても大丈夫」 | 協力工務店の許可・保険を提案書に明記する |

根拠: 国交省「原状回復をめぐるトラブルとガイドライン」。通常損耗・経年変化は貸主負担、補修は毀損部分を含む最小単位が原則。**法令の判断は論点整理まで。最終確認は専門家へ。**

### A-8. チャネルの優先順位

2. **業界団体**（大阪府宅建協会 北摂支部、日管協 大阪府支部、全日 北大阪支部）

4. **交流会**（不動産業者限定）
5. **メール**（AI下書き → 岩崎承認 → 1通ずつ送信）
6. **訪問**（紹介・メールの後追い）

### A-9. 清掃だけで入るとき（管理会社営業の入口。別リストは作らない）
一気通貫の提案が重いと感じる相手、または「今すぐ1室お願いしたい」と言われたときは、清掃単体で受ける。
- 出す価格は `01_products.md` の価格表のみ。管理会社直請けは 1K美装 13,000円／エアコン 9,000円。
- **受けたら必ず次の一言**: 「次の退去のときは、立会からお預かりすることもできます。写真つきの負担区分表をお出しします」。清掃単体で終わらせない。
- 完了報告に写真をつけて出す。それが次の提案書の実績になる。
- **受ける前に大槻の空きを確認する。** 埋まっているのに受けて外注に振ると、粗利は5%しか残らない（実績値: 請求明細書）。
- 稼働が埋まっているときは、量を増やさず **安い下請けを直請けに入れ替える**。同じ手間で1室4,000円増える。

## B. 燃料（パトロール給油。LIOAS 岩崎名義）

詳細は `docs/research/patrol-fueling.md`。要点のみ。

### B-1. 勝ち筋
利益 ＝ 数量 × 取り分。**件数より1件の数量。** 配送料の安い大阪市内・阪神間（尼崎〜明石）に絞る。
パトロール給油は「給油所まで往復する時間と人件費」を売っているので、単価だけの勝負にならない。巡回の時間帯・頻度・緊急対応も競争軸。

### B-2. 狙う業種
①建設・解体・産廃（重機・ダンプ・クレーン。主戦場）②運送業（トラック。車庫で継続数量が読みやすい）③バス事業者 ④A重油ボイラーの工場（エリア限定）。
扱う燃料は **軽油が基本**、灯油・重油はエリア限定。給油対象は 重機・トラック・ダンプ・クレーン・タンク。
タクシーは対象外（LPガスが9割超）。

### B-2-2. 向く顧客の条件（上位3）
1. **重機を自社保有し、現場が商圏内**。重機は公道を自走できず給油所へ持っていけない。代替は携行缶だけ。
2. **自家用給油設備（インタンク）を持っていない**。新設は 1,500万円級（仮置き）。「設備投資なしで同じ効果」が刺さる。持っている顧客はタンク納入の提案に切り替える。
3. **稼働時間が給油所の営業時間と合わない、または給油所から遠い**。早朝出庫・深夜帰庫の運送業、土日稼働の現場。

### B-2-3. 言ってはいけないこと（消防法。判断は専門家へ）
- ガソリンの直接給油ができる、と言わない（**原則不可**）。
- 「何リットルでも現場で給油できる」と言わない（同一場所での給油量が指定数量 1,000L 未満が条件）。
- 顧客側の届出が不要だと言い切らない（同一場所 200L 以上で少量危険物の届出が必要になるのが一般的）。

### B-3. 接触前の必須チェック
1. **配送業者6社（富士油脂産業、有限会社エスジー、郵船商事、イトー（堺市）、三政商事、東洋エネック）の既存顧客ではないか。** 該当なら連絡NG。
2. 与信の簡易チェック（登記、反社、支払遅延の風評）。
3. 自家用給油設備（インタンク）の有無 → 提案の形が変わる。

### B-4. 名乗り方（三層構造の説明）
契約主体はモリカワ商事、窓口は LIOAS、実働は岩崎。**この関係を初回接触から一貫して説明する。** 説明の型は `docs/research/patrol-fueling.md` §8。

### B-5. 言わないこと
- 価格・供給条件・品質を CORLY / 岩崎が約束する表現。正式な提示はモリカワ商事。
- 競合（三和エナジー、平野石油）の悪評。
- 出所が説明できないリストの使用（カミックスのリストは使わない）。

## D. 電話の台本（会議A 2026-09-30。価格は言わない。名乗りは社名・氏名・用件を最初に）

### D-1. 管理会社への初回電話
**受付突破**
「お世話になります。豊中で賃貸管理をしております、庄栄興産の岩崎と申します。退去立会と原状回復の件で、管理のご担当の方か、業者さんを決めておられる方はいらっしゃいますか。」
（「どういったご用件で」）「同じ管理会社として、立会が重なった時の1件だけをお預かりする仕事をしておりまして、そのご案内です。売り込みの電話が多いのは承知の上で、10分だけお時間をいただきたく。」

**担当者・決裁者に繋がったら（30秒）**
「庄栄興産の岩崎です。うちも豊中の管理会社で、退去の立会から工事・清掃・完了確認までを自分たちで回しているのですが、同じことを他の管理会社さんの分もお預かりしています。立会に写真と負担区分をつけて、オーナーさんにそのまま出せる報告にしているのが特徴です。」
「一つだけ伺ってよろしいですか。今、退去の立会はどなたが出ておられますか。」

**アポの一言**
「その立会報告の見本を1枚お持ちします。10分で結構です。来週の火曜の午後か、木曜の午前、どちらが空いていますか。」
（価格を聞かれたら）「清掃は 1K 美装 13,000円（税別）から。立会と工事は部屋を見てからでないと、いい加減な数字になるので、見本と一緒に目安をお持ちします。」（登録価格のみ。仮置きの単価は言わない）

### D-2. 燃料 — ミニローリー会社（尼崎。2026-09-30 の新ターゲット）
条件は登録済み（2026-09-30）。開始時期・掛売り・住所だけ未登録。
**現地（スタンドや路上で声をかけるとき。30秒）**
「すみません、燃料販売のモリカワ商事の代理店、LIOAS の岩崎です。この先に モリカワの燃料事務所ができます。軽油と灯油、カード給油で朝6時から18時（予定）。**ここで積むより安くなります。** 数字はモリカワから出すので、一度見に来てもらえませんか。」
→ 名刺を渡す →「いまは1日どれくらい積まれますか。朝は何時から動いてますか。」

**電話（社名が分かった先へ）**
受付: 「モリカワ商事の代理店、LIOAS の岩崎です。燃料の仕入れ・配車のご担当の方はいらっしゃいますか。」
担当: 「尼崎南の ENEOS のすぐ近くに、モリカワ商事が燃料事務所を開きます。軽油と灯油、カード給油、6時から18時の予定です。**いま積んでいる条件より安くなる**ので、御社の1日の積み量と時間帯に合うか、5分だけ確認させてください。」
聞く順: ①いまどこで積んでいるか ②1日・月の積み量（L） ③積む時間帯（早朝・夜・土日） ④掛けかカードか ⑤締めと支払 ⑥困っていること（待ち・営業時間・締め）
出口: 「開所の案内を出すとき、真っ先にお知らせします。見に来られる日を1つください。」
言わないこと: 具体的な単価・値引き幅（モリカワ商事が出す）、大光商事や他社の悪評、「何でも入れられる」「掛けでいける」（掛売りは未登録）。
断り: 「今ので困ってない」→「替える話ではなく、朝早い日や急ぎの日の二番手として、開所したら一度だけ見に来てください。」／「うちは元売と契約がある」→「承知しました。契約に触らない範囲で、スポットの積み場として覚えておいてください。」

### D-3. 燃料 — エンド顧客（副ターゲット。会議A）
「お世話になります。燃料販売会社モリカワ商事の代理店、LIOAS の岩崎と申します。トラック（重機）の燃料・給油のご担当の方、配車のご担当か、工務・資材のご担当はいらっしゃいますか。」
繋がったら: 「ご契約とご請求はモリカワ商事、窓口は私、配送は地元の配送会社という形で、車庫や現場まで来て車両に直接給油する配達給油をやっています。売り込みというより、御社の形に合うかどうかを先に確かめたくてお電話しました。」
聞く順: どこで入れているか（カード／ローリー）→ 自社タンクの有無と容量 → 台数（重機・発電機）→ 月量と油種 → 入れる時間帯。月量 5,000L 未満でタンクも重機も無ければ無理に進めない（仮置き）。
現場確認のアポ: 「車庫を一度見せてください。タンクの置き場と入れる時間帯を見れば、来週には数字を出せます。」

### D-4. 断られ方別の返し
| 断り | 管理会社 | 燃料 |
|---|---|---|
| 今は間に合っている | 「切り替えの話ではなく、立会が重なった時の1件だけ受ける先として、名刺と報告の見本を置かせてください」 | 「今の業者さんを替える話ではなく、現場が増えた時や急ぎの二番手として、車庫だけ見せていただけませんか」 |
| 業者は決まっている | 「その業者さんを外す話ではありません。次の退去1件、立会だけ、報告の形を見て使えるか判断してください」 | 「決まっているのが当然です。今の締め・支払と配送の時間帯だけ教えてください。それより良い形が出せなければ引き下がります」 |
| 担当者不在 | 「お名前と、お戻りの時間帯を。○時にこちらからかけ直します」（折り返しは頼まない） | 同左。「配車の方は朝何時ごろなら事務所におられますか」 |
| 資料を送って | 「お送りします。ただ紙では伝わらないので、10分だけ持参させてください。難しければ宛名とメールを」→ 送付後3営業日に自分から電話 | 「御社に合うかは車庫を見ないと書けません。見に行く方が早いです」 |

### D-5. 電話の法令・信用（論点整理まで。最終確認は専門家へ）
- 特定商取引法の電話勧誘の規制は消費者向けが対象で、事業者間は原則対象外と理解。ただし **個人の自主管理オーナーへの電話は消費者扱いになり得るので、専門家確認まで行わない**。事業者相手でも「社名・氏名・用件を最初に言う」「断られた先は連絡NGにして再度かけない」を守る。
- 「庄栄興産の岩崎」「LIOAS の岩崎」と名乗る根拠（メール1本でよい合意と名刺）を先に揃える。
- 「資料を送って」と言われたメールは相手の求めによる送信。それ以外は公表アドレスにだけ、承認のうえ1通ずつ。

### D-6. 毎日数える3つ（会議A）
①決裁者・担当者と話せた数（留守・受付止まりは数えない。架電本数は追わない）②「物」の約束数＝立会お試し＋現場確認の日時 ③期限切れの次アクション件数（0にしてから寝る）。

## C. 共通

### C-1. 活動の型
- ステージ: 未接触 → 初回接触 → 提案済 → 交渉中 → 成約 / 失注
- チャネル: 紹介 / 飛び込み / 電話 / メール / LINE / 展示会 / 業界団体 / Web問い合わせ
- 活動結果: 会えた・話した / 留守・不在 / 折り返し依頼 / 資料送付済 / 断られた
- 失注理由: 価格 / 時期 / 既存契約 / 不要 / 不明（1語で残す）

### C-2. プレイブックの育て方
岩崎が訪問後に「〇〇に行った、こう言われた、こう返した」と話す → outside-sales が活動ログに記録し、有効だった返しをこのファイルの候補として提案 → **岩崎が「採用」と言ったものだけ**を表に載せる。

### C-3. 採用済みの返し
（未登録。最初の商談から溜める）
