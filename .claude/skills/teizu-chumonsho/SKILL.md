# ティーズプラス 注文請書の返信

株式会社CORLY(岩崎大樹)が、株式会社ティーズプラスからの発注書を受けて注文請書を返信する作業。

## 前提
- 発注書PDFは4ページ固定。1=発注書、2=注文請書、3=指示書、4=施工完了報告書。
- 今回記入するのは **2ページ目の注文請書だけ**。完工報告書(4ページ目)は書かない。
- 「注文請日」は **発注日ではなく記載日(この作業をした今日の日付)**。日付はシステムの「Today's date」を使い、推測しない。
- 担当者は常に「岩崎大樹」、TEL は 06-4256-2693。社印は `assets/stamp.jpg`。
- Pythonは `python3`(pymupdf必須。無ければ `python3 -m pip install pymupdf pillow`)。

## 手順
1. **メールを特定**: `mcp__Gmail__search_threads` で物件名・号室から検索(例 `subject:物件名 号室 after:YYYY/MM/DD`)。発注者は info@t-s-plus.co.jp。同じ号室の発注書が複数ある(日程変更分・過去分)場合は、ユーザーが見せた発注書の注文No・工期と合うものを選ぶ。
2. **本文とファイル名を取得**: `get_message`(PLAIN_TEXT) で添付の `filename` と、本文末尾のティーズプラス担当者名(嶋田/池田など)を控える。
3. **PDFを取得**: `get_message`(RAW) はサイズ超過でtool-resultsのJSONに保存される。`python3 scripts/extract_pdf.py <そのJSON> <作業用>/src.pdf` で取り出す。
   - メールが約6MB超だとGmail接続が切れて取得できない。その場合はユーザーにPDFのアップロードを頼む。
4. **内容確認**: 取り出したPDFの2ページ目テキストで、物件名・号室・注文No・発注日がユーザーの示した発注書と一致するか確認してから進める。
5. **記入**: `python3 scripts/fill_chumonsho.py <src.pdf> <out.pdf> <今日 YYYY-MM-DD>`
   - 出力は注文請書1ページのPDF。必要なら `pymupdf` で画像化して目視確認する。
6. **ファイル名**: 元の添付ファイル名とまったく同じにする(例 `【発注書】物件名_号室_CORLY様.pdf`)。全角スペース・Ⅰ/Ⅱなどは手打ちせず、Pythonで `shutil.copy` し、`''.join('\\u%04x' % ord(c) for c in fn)` で作ったエスケープ文字列を SendUserFile に渡す(手打ちで文字を取り違えた実績あり)。
7. **ユーザーに渡す**: `SendUserFile` で請書PDFを送る。
8. **返信の下書き**: `mcp__Gmail__create_draft` を、元メールのIDを `replyToMessageId`、宛先 `info@t-s-plus.co.jp`、件名 `Re: <元の件名>` で作る。添付は付けない(添付は破損の恐れがあるため、ユーザーがGmailで手動添付する)。本文:

```
{担当者}様

お世話になっております。
株式会社CORLYの岩崎です。

【{物件名}　{号室}】の発注書を確認いたしました。
注文請書を添付いたしますので、ご確認の程よろしくお願い致します。

株式会社CORLY
岩崎
```

9. **報告**: 下書きのURLを伝え、「請書PDFをGmailで添付して送信してください」と添える。

## 注意
- 写真(鍵・部屋番号など)は、この請書の段階では通常ない。来たらJPEGのまま `SendUserFile` する。
- 社印画像が無くなったときは、ユーザーに画像を送ってもらい、白背景に合成して正方形(260px程度)にして `assets/stamp.jpg` を作り直す。
- 完工報告(4ページ目の記入、着工日・完工日・施工者)は別の作業。このスキルでは行わない。
