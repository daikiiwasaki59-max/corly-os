# 写真の入れ方

このフォルダに写真を置いて `python3 scripts/import-photos.py` を実行すると、
サイズ調整・圧縮のうえ `site/assets/img/ph-*.jpg` に変換され、ページ再生成で自動的に使われます。

## ファイル名（この名前で置く。拡張子は jpg / jpeg / png / webp どれでも可）

| ファイル名 | 使われる場所 | 推奨する写真 |
|---|---|---|
| hero    | トップのメイン | 清掃作業中のスタッフ、または清掃後の明るい室内（横長） |
| vacant  | 空室清掃（カード・ページ） | 清掃後の空室、キッチン、浴室 |
| regular | 日常・定期清掃 | エントランス、共用部、床洗浄 |
| store   | 店舗・飲食店清掃 | 厨房、グリストラップ、客席 |
| report  | トップ「作業は、写真で報告します」 | 報告書の実物 |
| work1〜work4 | トップ「施工写真」 | 作業前後 |
| office  | 会社概要 | 事務所外観 |
| staff   | 予備 | スタッフ |

例: `photos-inbox/hero.jpg`, `photos-inbox/work1.png`

## 無料素材を使う場合
Unsplash / Pexels / Pixabay はログイン不要でダウンロードできます（商用可・クレジット表記不要）。
写真AC・ぱくたそは無料会員登録が必要です。ダウンロードした写真を上の名前に変えてここに置いてください。
GitHub のブラウザ画面で `photos-inbox` を開き「Add file → Upload files」でドラッグ＆ドロップできます。
Google ドライブに `HP写真` フォルダを作って入れてもらっても取り込めます。
