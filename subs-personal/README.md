# サブスク管理（個人用）
Meta Muse の「サブスク監査」を参考にした、手入力＋明細貼り付けの管理ツール。無料・サーバー無し・端末内(localStorage)保存・外部送信なし。
使い方: `python3 -m http.server` → ブラウザで開く。（file:// 直開きでも動作）
- 登録: サービス名・金額・周期・次回更新日 → 月額/年額換算、更新7日前アラート
- 見直し候補: 「使っていない」チェック、または最終利用から一定日数（既定60日は仮置き、設定で変更）
- 明細貼り付け: 同一内容・同一金額が約1か月/1年おきに並ぶ行を、定期課金の「候補」として抽出（推定）
- バックアップ: JSON書き出し/読み込み
限界: 銀行連携・メール自動検出・自動解約・プッシュ通知は無し（意図的）。個人用のコードなので、CORLYのリポジトリから別リポジトリへ移すこと。
